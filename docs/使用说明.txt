IndexTTS2 v3 — 便携分发包
====================================

这是什么
--------
开箱即用的 IndexTTS2 本地语音克隆服务（WebUI）。已内置 Python 运行时、
全部依赖、模型权重与网页界面，无需安装任何环境。

v3 新增（相对 v2）
--------
- 音频剪辑台：生成结果可直接裁剪、调音量（-24~+24 dB，削波时给
  「拉到无损上限」一键修正）、变速 0.5~2.0 倍（保音高不变）；
  支持撤销重做，源音频与编辑结果分开下载
- 段间停顿可调（10~500 毫秒，默认 200），长文本听感更自然
- 术语词汇表：单条删除、一键清空，以及可选的「级联替换」开关（默认关）
- 停止生成：生成中可随时停止，不再被记为失败，停止后无需重载模型
- 队列提示更准：把你正在生成的任务也算进排队人数
- 模型管理：保存配置不再排队等推理；生成中也能安全卸载模型
- 参考音频超过 15 秒会明确提示（仅取前 15 秒）
- 文本长度改为软提示：2000 字起提醒，10000 字才硬限
- Qwen 情感模型改为按需加载：默认省约 1.5 GB 显存
- 界面：三栏布局断点修正、宽屏左右对齐、开关支持键盘操作

系统要求
--------
- Windows 10/11 x64
- NVIDIA 显卡（驱动支持 CUDA 12.8；显存 8GB 即可运行）
- 解压后需约 18 GB 磁盘空间
- VC++ 运行库（绝大多数系统已带；若启动报缺 DLL，安装
  "Microsoft Visual C++ Redistributable 2015-2022 x64" 即可）

使用方法
--------
1. 把整个文件夹解压/复制到任意位置，保持目录结构完整，不要单独移动里面的文件。
2. 双击 start_server.bat —— 会启动服务并自动打开浏览器
   （地址 http://127.0.0.1:7860，浏览器没弹出就自己打开这个地址）。
   注意：服务在这个窗口里运行，【关闭窗口服务就会停止】，最小化即可。
3. 页面顶部三个页签：
   - 语音合成：上传参考音频（3~10 秒）→ 输入文本 → 点「生成语音」。
     右侧「生成历史」栏保留本次运行生成过的音频，点一条即可载入播放器
     （也能删除单条记录）。
   - 预设管理：保存/复制/改名常用音色与参数
   - 模型管理：查看运行状态、加载/卸载模型、调整加速项
4. 生成完成后可在结果区直接编辑：裁剪、调音量、变速，再单独下载编辑后的文件。
5. 停止服务：关闭启动窗口，或双击 stop_server.bat。
   生成过程中点「停止生成」可以随时中断，不会算作失败。

常见问题
--------
- 首次点「生成语音」需要 30~60 秒加载模型（页面有进度提示），之后就是秒级。
- 显存占用约 6~8 GB；若不足，在「模型管理」页关掉 w2v-bert 半精度可省 1GB。
- 界面卡死/报错时：双击 stop_server.bat 再双击 start_server.bat 重启即可。
- 生成结果保存在 outputs\，重启不会删除（保留 14 天）。
- 端口被占用：编辑 start_server.bat 里的 --port 7860 改成其他端口。
- 不要删除 runtime\ 文件夹（Python 运行时在里面）。

性能说明（相对官方原版的优化）
--------
- 同长度音频推理 151s → ~21s（BigVGAN 修复 + 半精度矩阵 + 负优化项移除）
- 显存：8GB 卡可跑全量模型（w2v FP16 默认开启再省 ~1GB）
- 全程离线运行，不联网、不回传任何数据。

技术细节（面向懂行的用户）
--------
- FastAPI + 原生 JS 前端，替换了官方 gradio WebUI
- Python 3.11.9 / PyTorch 2.8.0+cu128 / transformers 4.52.1
- 默认推理配置：FP16+S2MEL_FP16+W2V_FP16+QWEN_FP16 开，cuDNN 调优关，
  diffusion_steps=25，inference_cfg_rate=0.7（与「推荐配置」按钮一致）
全能音声工作台（后加的扩展，原功能一行未改）
====================================
入口
--------
主界面右上角「全能音声」，或 http://127.0.0.1:7860/longform
直达工作台：http://127.0.0.1:7860/longform?view=board

页面结构
--------
顶部（两行）：
  第一行：台本切换 / 新建 / 导入 / 保存 ······【保存并进入时间轴】/ 夜间 / 返回主界面

裁剪片段
--------
拖片段左右边缘都能裁；往回收可以把片段拉回完整长度（不会丢素材）。
左边被裁过、又挪过位置的话，右键片段选「↔ 恢复完整片段」一步还原。
素材片段的「源长度」取文件的真实时长，所以刷新页面后照样能拉回去。

预览倍速
--------
传输条上的「倍速」下拉：0.5× ~ 3×，也可以「自定义…」填 0.2~4 的任意值。
只影响试听，导出混音 / 工程永远按原速。

关键帧录制（音量 / 声像 / 空间距离，三个都能录）
--------
属性面板「关键帧」里，三个页签下面都有同一行：
  ⏺ 录制音量 / ⏺ 录制声像 / ⏺ 录制空间距离    每 [0.1] 秒一个点
点开始会自动播放，你一边听一边拖：
  · 音量/声像：拖下面出现的实时滑块
  · 空间距离：拖上面摆位网格里的声源点（或距离滑杆）
再点一次停止 → 按「间隔」生成关键帧。时间按你**听到的播放位置**记，2 倍速试听也录不歪。
间隔单位是秒（0.02~2），默认 0.1 秒一个点；手不动就不重复记点。

素材库（三个都是全局的，跨台本/工程共用）
--------
· 🔔 音效库   longform/sfx/        成品音效
· 🎙 音色库   longform/refs/       参考音频 / 克隆音色（工作台里那份，同一份）
· 📥 导入台   longform/materials/  还没处理、没标记的原始素材
时间轴的素材面板就是这三个页签；以前那个「本工程」页签已经删掉。
插入时会把文件拷一份进当前工程（工程自带素材、换机器也能开），但它不再是一个单独的库。
要加新素材：点「📥 素材导入台」上传 → 处理 → 存成音效或音色。

**文件夹（三个库通用）**
素材多了以后，靠搜索框找不动（名字还常常是自动编号的），所以三个库都有一层目录：
  · 列表上方那条：`全部 › 父级 › 当前`，下面是当前层的子文件夹（chip 上写着含子目录的数量）；
    点 chip 进入那一类，点面包屑回上一层；
  · 「＋ 文件夹」在当前层新建（可以建子文件夹，最多 5 层）；进到某个目录后还能「改名 / 删除」；
  · 归类：右键素材 →「📁 移动到文件夹」，或者导入台里勾选多个 → 点「📁 移到文件夹」；
  · **删文件夹不会删素材**：里面的东西回到「未归档」，音频一个都不动；
  · 三个库、三个页面（工作台 / 时间轴 / 高级音频处理台）看到的是同一套目录；
    在音效台底部的「📁」选好文件夹，存出来的多条音效会一起放进去；
  · 列表一次渲染 300 条，多的点「显示更多」，几百条也不会卡。

**多选（音色库 / 音效库，v0.31 起）**
有了文件夹，一次整理几十条就得先能多选：
  · 每行左边有勾选框；也可以按住 **Ctrl 点行**加选；
  · 勾上之后列表上方出现批量条：**已选 N · 全选 / 反选 / 清空**，右边是
    **📁 移动 / 🏷 加标签（只音色库）/ 📌 置顶 / 🗑 删除**；
  · 右键点在「已勾选的其中一条」上，菜单**顶部**直接给这几个批量动作（不用再去点按钮）；
  · 删除音色只删库里的参考音频，台本里已经生成的语音不受影响；
    删除音效进音效库的 `.trash`，可以恢复；
  · 和导入台的多选是同一套交互，三个库不用各学一遍。

空间音频面板
--------
· 摆位是一张网格 + 三个平面：X/Z 俯视、Y/Z 侧视、X/Y 正视（dearVR 那种）。
  俯视看方位和距离（带距离环，数字会自动躲开声源），侧视/正视看高度。
· 网格中间的人头按平面换画法，照着 dearVR 画的：
  俯视 = 头顶朝上看，鼻子凸起朝上（= 正前），头梁横跨、两侧耳杯；
  侧视 = 朝右的侧脸（额头、鼻尖、下巴、后脑）+ 耳杯圆 + 头梁；
  正视 = 正面头型 + 头梁 + 两侧耳杯 + 脖子。
· 网格左边是高度（仰角）竖滑杆，上方是方位滑杆；声源是圈里带点的标记，虚线连着头。
  声源超出视野时沿原方向贴到网格边上（不会消失），圈会变淡提示。
· 录制：见上面「关键帧录制」，距离和音量/声像用的是同一套。
· 片段右键还能「恢复完整片段」。

存储清理（🧹 清理空间）
--------
为什么能清出这么多：**不是备份**。同一份音频会在「音效库 / 素材库 / 工程 media」
各存一份（一个 130MB 的音效就是 390MB），导出的混音与工程 zip 留在工程里，
删掉的台本/素材只进回收站不真删，旧版打包导出还会留下 .trash_* 暂存目录。
点「🧹 清理空间」会按分类列出体积（条形图），勾选后一键清：
  回收站 / 导出产物 / 历史快照 / 波形缓存 / 导入缓存 / 主程序生成历史 /
  音效台分离作业 / 分离中间文件 / 运行日志 / 孤立音频 / 工程里的重复素材
其中「孤立音频」「重复素材」默认不勾（可能影响工程），其余可放心清。
顶部的「✓ 只勾推荐项」= 只选安全的那几类，一屏 11 类不用逐个点。

· 「音效台分离作业」是高级音频处理台「① 准备素材」落盘的副本（每个都是整条源音频）；
  默认只留最近 8 个，这里清也只清旧的，**最新那个永远保留**（可能正开着页面）；
· 「分离中间文件」是 BS-Roformer 的输入/输出临时 wav，正常跑完会自己删，异常退出才会留下。

  「📥 素材导入台」= 直接打开导入台抽屉（不必先进音色/音效库）；也支持 /longform?desk=1&target=sfx 直接进来
中间：左「我的台本」 | 中「编辑 / 工作台」 | 右「批量 / 生成 / 导出」
两条竖向分隔条可拖动改宽，宽度会记住。
「全局默认参数」「音色素材库」「参数预设」点开是右侧抽屉（Esc 或点遮罩关闭）。
「默认参数」已改名为「全局默认参数」——它的作用范围是整个台本（新行 + 没有单独覆盖的行），
不是只改当前这一句；单句/多句要改请用行右键或「批量改属性」。
设置抽屉最上面现在是「**人物标签**」块（跨台本）：人物库 + 「🧠 智能识别人物」+
「智能导入时按人物自动设音色」。它不是台本默认参数的一部分 —— 换台本、换章节都共用，
用法见后面「人物标签」一节。

编辑区（紧凑单行）
--------
一行只占一行高：序号 · ＋ · 文本 · 字数/时长 · 状态 · [▶ 试听][⟳ 生成][⤓ 导出][⋯] · 停顿框。
时长那栏：**没生成**显示「≈x.xs」（按字数估），**生成过**直接显示「实际 x.xs」；
如果文本/参数改过但还没重生成，会写「实际 x.xs（待重生成）」。
没加句中标签时不会有第二行，加了才变高一点。
行首的「＋」（悬停可见）→ **插入句中标签**（位置在弹窗里拖滑杆选，不用非要在句首）。
完全空白的行（没文字、没音频、没句中标签）末尾会多出一个「✕」，点一下直接删掉这行；
一旦开始打字它自动隐藏，把文字删空又会回来。

句中标签的 chip 长这样：〔标签名〕@位置 +500ms 🔔
  点名字 → 打开编辑窗：标签名 / 位置（数字框 + 拖动条，旁边实时算「句中约 x.xx 秒」）/
           延迟（默认 500ms）/ 挂载音效（下拉 + 试听 + 音量）
  点 ✕ → 删除
· 句中标签**默认带 500ms 延迟**：它大多落在句子中后段，不加延迟容易和上一句末尾的句间标签
  挤在同一时刻。延迟调 0 就是「正好卡在那一字上」。
· 句中标签本身不出声，只标位置；挂了音效才会在「句中时间 + 延迟」响，并在时间轴上生成对应素材。

切换「编辑 / 工作台」时，顶部那一句会自动对齐 —— 两边看到的是同一句。

改文本快捷键
--------
回车            句子中间 → 从光标处切成两句；句子末尾 → 在下面新建一行空句（光标自动过去）
                行为像写小说：句中回车分句、句末回车加行，不用先点「末尾加一行」
Backspace       光标在行首时并入上一行
Delete          光标在行尾时把下一行并进来
Ctrl+Enter      只生成这一行
Alt+空格        试听当前行
↑ / ↓           行间移动；行尾连按两次 ↓ 在末尾加一行
句间标签：鼠标移到两行之间的空隙、且落在「编辑区中间一半宽度」内，才展开插入带，
          「＋ 句间标签」跟着鼠标出现，点它即插；两侧各 1/4 不触发，扫过不会误弹。
          工作台视图里卡片之间也有同样的插入带。

行右键菜单（编辑区和工作台都能用）
--------
在任意一句上点右键（行内「⋯」按钮也是同一个菜单）：
  编辑属性（音色 / 情感 / 停顿）…
  复制文本 / 复制这一句（在下方插入副本，行级参数和句中标签一起复制）
  只选这一句 / ↑ 从这一句往前全选 / ↓ 从这一句往后全选
  在下方插入空行 / 在句首插入句中标签 / 在下面插入句间标签
  ▶ 试听 / ⟳ 重新生成 / ⤓ 导出 / ↩ 撤回修改（有改动时才出现）
  删除这一行
句间标签行也有自己的右键：修改标签 / 选中 / 前后全选 / 删除。
工具栏选择区还有「↑ 往前全选」「↓ 往后全选」两个快捷按钮，
锚点是「光标所在句」，没光标就取「最后点过的那句」。
全选只作用于当前筛选后看得见的行，不会偷偷选到被筛掉的内容。

智能导入（顶栏「🧠 智能导入」）
========
把一份现成的文件读进来，**先看它长什么样**，再决定怎么切、怎么分组，一次性建成台本 + 分组任务。

支持的格式
--------
  · txt / md      纯文本
  · docx          Word（解压读正文，标题样式识别为章节；不需要装 Office）
  · srt           字幕（解析成带时间码的条目）
  · csv / tsv     表格（自动认「正文 / 角色 / 标签 / 备注」表头，也可以手动指定列）
  · fountain      剧本格式（.fountain：标题页、场景头、角色、括号提示、对白）
也可以什么都不选，直接把文本粘进第一步的框里（「看个示例」有一份示例剧本）。

三步流程
--------
① 选文件：拖进来或点击选择；解析后显示「格式 · 字数 · 字幕条数」和正文预览。
② 识别类别：自动判断这份文本属于下面 5 类里的哪一类，给出**判断依据**和匹配度；
   可以换成别的类、调选项、套预设（每类下面都有说明与提示）。
③ 预览编辑：按分组列出所有分段，每一段都能改；想看「念出来是什么样」就点
   「👁 正文预览」（第 3 步底部也有一颗），改完点「导入并建 N 个分组」。

剧本头部的「【场景】/【人物】/【字数】」
--------
短剧 / 动态漫的稿子常带一行行元信息。现在它们会被认出来，不再当成正文：
  · 【场景】…  → 场景（「场景 + 角色」分组时做前缀），也会记进备注；
  · 【人物】嘉然（活泼吃货，软乎乎）、乃琳（…）→ 解析成**角色卡**：
    导入预览顶部显示 👤 嘉然（活泼吃货、软乎乎）… + 「＋ 建进人物库」，
    点一下就把人名和属性标签建成人物，之后去「设置 → 人物标签」绑音色；
  · 【字数】/【时间】→ 只做展示；【备注】/【说明】→ 记进备注。
  · 这几行**不进正文、不朗读**，但「原文本预览」顶部会以「原文信息」原样显示
    （虚线框），不会像以前那样被吃掉。

关于「只有一个时间码」
--------
以前只要有时间码 + 波浪线/箭头就判成字幕稿 —— 剧本开头写一行 `[00:00:00]`，
整篇就会被当成一条字幕，后面的「角色：」全废。现在：
  · 有区间箭头（`-->` `⇒` `→`）才算单条字幕；
  · 只有零散时间码时，**至少 2 条**才判字幕稿；
  · 都不满足就按普通文本识别，剧本会走「剧本类 → 按角色分组」。

5 类（按特征自动判定，可手改）
--------
  1. ⏱ 时间轴类 ── 有绝对时间码（srt、[00:01:23] 行首、整行的 00:12）
  2. 🎭 剧本类   ── 有显式角色前缀（「阿澈：…」，或角色名单独一行跟着台词 / fountain）
  3. 📖 小说类   ── 含成对引号对白（「」『』“”""）
  4. 🏷 指令类   ── 有【镜头 1】/【停顿 3 秒】这类标签，或一行一句的强换行
  5. 🧩 纯文本   ── 前四类特征都没有，按句子长度切（兜底）

  判定是打分制的：比如 srt 直接判时间轴类；出现 ≥2 个「角色：」前缀就判剧本类；
  ≥2 处引号判小说类；≥2 个指令标签或 70% 以上的行都很短判指令类。
  分数不够就退回纯文本。第二步顶部会写清「为什么这么判」，并列出其他可能性，
  点一下就换过去。

每一类怎么切（策略与选项）
--------
① 时间轴类
   · 一条时间码 = 一段；时间码只当属性，绝不进正文，也不进备注。
   · 延迟按空档算：空档 = 下一条开始 − 上一条结束。
       小于 120ms  → 0（字幕连排，硬加停顿会拖慢）
       120ms~3000ms → 原样保留（配音的呼吸缝）
       超过 3000ms  → 截到 3000ms（多半是换镜头，全按原样会越拖越长）
   · 延迟策略可选「智能 / 固定值 / 不加延迟」；上面三个阈值、空档系数(0.2~2.0)都能改。
   · 出现时间写进行属性 t0/t1（行上显示 ⏱），进时间轴按它落位。
   · 双语字幕（一条里中英两行）可拆成两条，也可「只要中文 / 只要外文」。
   · 分组：不分组 / 按语种 / 按说话人 / 按时间段（每组 N 秒）。
   · 预设：标准字幕配音 · 双语分开配 · 只要中文 · 长片分段。

② 剧本类
   · 角色名不进正文，只用来分组或记备注；换人、换场必断。
   · 同一角色连着说几句会合并到单段上限（可关）。
   · 场景头（INT./外景/第 3 场）默认写进备注，不朗读。
   · 括号动作（（收伞）（雨声））写进备注，也可以整段丢弃；
     「阿澈（低声）」会自动剥掉括号，提示单独记备注。
   · 角色写法可指定「行内冒号 / 角色单独一行」，默认自动数比例。
   · 分组：按角色 / 按场景 / 场景+角色 / 按章节 / 不分组。
   · 预设：短剧广播剧 · 按场景排 · 动态漫（格+角色）· 播客访谈。

③ 小说类
   · 引号里的内容单独成段（当台词），引号外的叙述留旁白；
     一句里既有叙述又有台词时，在引号边界切开，不会粘在一起。
   · 括号里的内容（心理活动/动作）可单独成句，或只记备注不朗读。
   · 可关掉「保留引号字符」，只读字。
   · 章节识别：自动（第 x 章 / # 标题）/ 只认 # / 空行分章 / 关。
   · 分组：按章节 / 旁白·台词 / 章节+旁白台词 / 不分组。
   · 预设：有声书 · 旁白台词分开配 · 绘本（短句）· 只读旁白。

④ 指令类
   · 标签不朗读：【镜头 3】可以写进备注、当分组名、直接丢掉、或留在正文里。
   · 【停顿 3 秒】/（静默 5s）→ 真正的静默时长（上限可设，默认 30 秒）。
   · 强换行时一行一段、不合并；也可以关掉「一行一段」让它按上限合并，
     或勾「把过短的行并到下一行」。
   · 分组：按标签（镜头/分格/标题）/ 按章节 / 不分组。
   · 预设：短视频解说 · 按镜头分组 · 动态漫（按分格）· IVR（一行一条）。

⑤ 纯文本
   · 分段方式：按长度（切句后合并）/ 一句一行 / 一段一行（按空行）/
     一行一段（不切也不合，用来把「⤓ 导入原稿」下载的文件原样重来）。
   · 章节识别同小说类；分组：不分组 / 按章节 / 每 N 段一组（长文分批）。
   · 可以给每段后加固定停顿。
   · 预设：口播稿 · 逐句精修 · 按段落 · 长文分批 · 导入原稿（一行一段，不切分）。

每类都有「?」：说明 + 标准格式示例
--------
模板/类别卡的右上角「?」，或规则面板的「📄 说明 / 示例」，会打开这个类别的：
  · 详细说明（怎么认、怎么切、给什么选项）；
  · 支持格式 / 默认分组 / 单段上限 / 本文匹配度；
  · 规则清单；
  · 一段**标准格式示例**（mono 原样展示），可以「⧉ 复制示例」拿去改，
    也可以「用这份示例试一遍」直接填进第一步的粘贴框走一遍完整流程。

顺序 vs 分组（重要）
--------
分组只决定「哪些句子归一起（= 哪个批量任务）」，**不改变句子的先后**：
  · 同一组里的句子，按它们在原文里出现的顺序排（哪怕中间隔着别的角色）；
  · 生成的台本整体也按原文顺序排，角色/旁白交错的地方不会被打乱成
    「先所有旁白、再所有角色」；
  · 想调整顺序：预览里用 ↑ 上移，或在台本里拖 / 用「↑ 往前全选」批量改。

换类别会不会白干？
--------
  · 在第二步换类别 / 改选项 / 套预设，按「按…识别」重新跑一遍即可，不消耗任何东西；
  · 只有进了第三步、手动改过分段，再点「← 上一步」重新识别才会覆盖那些手改；
    想保留就先导入，再到台本里改。

分段安全（重要）
--------
  · 只在「引号 / 括号外面」的句末标点处切；**绝不在引号中间、半句中间切**。
  · 一句话本身就超长、又找不到安全切点时：保留整段并标为异常（预览里琥珀色 + 顶部提示），
    交给你手动拆——不会为了凑长度把台词切碎。
  · 单段最终还会被 MAX_LINE_CHARS（400）兜一层，防止极端文件写爆模型输入。

预览里能改什么
--------
  · 直接改文字（多行也可以）；✂ 在光标处拆分；⇧ 并入上一段；↑ 上移；✕ 删除
  · 分组名可改（导入后就是分组任务名）；每组可设音色 / 情绪 / 权重 / 停顿（= 批量继承）
  · 「＋ 新增分组」「＋ 在这一组末尾加一段」「与下一组合并」
  · 每段行尾的 🔊 / 🔇：去掉配音（文字留住、不进台本）或恢复；
    去掉的那段在卡片上变灰并标「🚫 不配音（不进台本）」，分组头写「另有 N 段不配音」，
    整组都不配音时写「整组不配音 · N 段（不会导入）」并灰掉整组；
  · 字幕来源的行会显示「⏱ 出现时间 · 延迟」

正文预览（第 3 步工具栏 / 底部「👁 先看正文预览」）
--------
按「导入后台本的样子」把全部文字连排成正文，一句一个色块（同色 = 同一组 = 同一音色），
读起来就是一份上了色的稿子，不是一张张卡片。

  · **窗口里是原文全文**：会上色的才会配音；动作 / 镜头 / 时间码这类只进备注的内容
    是灰色小字、不上色。
  · 去掉配音 ≠ 删除：右键第一项「🚫 去掉配音」只把颜色去掉（文字留在原位、不进台本），
    再点一次「✅ 恢复配音」就回来；真要删字用右键最后一项「🗑 从台本里移除」。
  · 顶部「按句选择」开关：开（默认）= 点一句 / 拖一段都按整句，Ctrl 点加选、Shift 连选；
    关 = 只处理你划中的那几个字（这几个字加下划线，前后文不受影响）。
  · 改归到别的分组 = 自动恢复配音（不用先点恢复）。
  · 右上角 ↶ 撤销 / ↷ 恢复（Ctrl+Z / Ctrl+Shift+Z），只作用于预览里的草稿。
  · **右下角「保存并按预览分组」**：点了才算定下来；直接关掉（或 Esc）= 丢弃，会先问你。
  · 右上角「⤓ 导入原稿」：下载这次导入的**真原文**（你拖进来 / 粘进来的那份，
    带【场景】、角色前缀、时间码，一个字不改），要改原稿就下它。
    台本页「原文本」里的「⤓ 导入原稿」也是同一份（老台本没存过原文时，退回按拆句结果导出）。

高级识别（第 2 步的开关 / 第 3 步工具栏的 🧠）
--------
稿子里没有「名字：」前缀、但名字写在旁白里（「你怎么才来？」李四说。）时用：
  · 按 前文点名 > 后置旁白 > 上文继承 的顺序认人，认出谁就按谁分组；
  · 一条线索都没有的句子仍退回 角色A / 角色B（默认行为，不受影响）；
  · 小说 / 剧本 / 纯文本三类都有；剧本已经有「名字：」前缀时会自动跳过；
    时间轴类和指令类没有这颗按钮。
  · 没名字的稿子（整行 [台词]、通篇没有人名）它也没办法，那还是交替 A/B。
  · 开关旁边还有一颗浅绿的 **🎭 识别说话人 · 分组 · 分音色**：一次做完三件事 ——
    认得谁在说 → 按角色分组 → 导入时按人物库自动套音色，点完直接落到第 3 步核对。
    左边那颗只管「规则开 / 关」，这颗是「帮我一次做完」，两个不冲突。

导入之后
--------
  · 顶栏两颗预览：📄 原文本预览（导入那一刻的全文，没进台本的句子是灰色虚线框）
    和 📝 当前文本预览（台本里现在有的句子，点一句跳过去选中）；窗口里一句一行、
    左边是行号，两个视图随时切换且停在原处；两颗都只读，右上角都能「⤓ 导入原稿」。
  · 多选删除：勾选多行后右键「🗑 删除选中的 N 行」，或顶栏「删除选中」；Ctrl+Z 一步撤回。
  · 每行都带「▤ 分组」「✎ 备注」小标（鼠标停上去看全文），慢语速多一个「慢」标，
    字幕来源的行还有一个「⏱ 0:12」的出现时间标；
  · 这三样都在「行属性」里能改：点小标（或 ⋯ → 编辑属性）改分组 / 附属备注 / 慢语速；
    没有备注的行鼠标移上去会出现一个很淡的「＋备注」；
  · 分组 = 批量任务，参数已经写进行级覆盖，可以直接「按分组生成」；
  · 备注不朗读，只做记录，会出现在导出的映射 CSV 里；
  · 「导出」页有「映射 CSV」：序号 / uid / 分组 / 正文 / 附属备注 / 慢语速 /
    出现时间 / 结束时间 / 时长 / 音频文件 / 状态，
    用于把每句音频对回剪辑工程（PR / 达芬奇 / 剪映的表格导入都能吃）。

批量改属性（工具栏 / 右侧「批量」页都有）
--------
先选中若干句，点「批量改属性」。弹窗里每一项左边都有独立勾选框，**只改打了勾的项目**：
  音色 / 情感（模式 · 权重 · 参考音频 · 8 轴向量 · 描述文本）/ 行后停顿 / 追加句中标签
  以及「清除所有行级覆盖（回到全局默认）」
改完已生成的行会标成「需重生成」，旧音频先留着，重跑才替换。

情感这一项收在一行里，**选了哪个模式才展开哪一块**：
  0 同音色 → 都不展开；1 情感音频 → 只展开「参考音频」；
  2 情感向量 → 只展开 8 轴滑杆 + 快捷填充；3 情感文本 → 只展开描述输入框。
「批量分组」的参数面板和「⚙ 设置 → 台本默认参数」也是同一套（后者补上了模式 3 的描述文本）。
以前三块同时铺开，既占地方又容易看错「到底哪个生效」；模式 3 还缺输入框，选了也没地方写。

句子改动标注与撤回
--------
每行右侧会出现：
  · 「改 N」小标签：鼠标停上去显示具体改了什么（文本显示插入/删除/替换的前后文，
    属性显示 旧值 → 新值，例如「情感权重：0.65 → 0.9」）
  · 「↩」撤回按钮：把这行恢复成生成时的文本与参数，标签变回「完成」，音频继续可用
  · 状态徽标：完成 / 需重生成 / 未生成 / 失败
重生成跑完后，状态与标注会自动复位（不再出现「已经生成好了却一直挂着需重生成」）。
工具栏「改动 N」按钮 = 只看改过的句子，再点一次回到全部。

智能分行
--------
工具栏「智能分行」：
  · 按标点分句：严格在 。！？；…—— 处切开（一句一行）
  · 按长度合并：短句并到接近字数上限，减少行数
  · 范围可选「只处理未生成 / 需重生成」或「全篇」（全篇会把已生成的行标成需重生成）

顶部统计 chips（各状态分开算，不会重复计数）
--------
句（语音行）/ 字 / 已生成 / 需重生成 / 未生成 / 失败 / 标签（句间/句中）/ 音频总长 / 全篇预估。
  · 「已生成」= 音频存在且和当前文本参数一致；「需重生成」= 有音频但内容/参数改过；
    判定看两样：内容指纹 + 「生成时快照 vs 现在参数」——只要文本和音色/情感/分段长度没动，
    就不会因为保存一次、改个停顿而被误标（以前打开就整篇「需重生成」的坑已修）；
    只改「停顿」「留白」（不进音频）不算过期；
    以前的老数据（指纹算法不同）会在打开时**自动认回完成**，不用手动重跑；
  · 左边「我的台本」卡片也按同一套统计显示（完成 / 待重生成 / 失败）；
  · 点任意状态 chip 等于按该状态筛选（再点一次取消），和「筛选」下拉是联动的；
  · 「全篇预估」= 已有音频 + 未生成部分按实测语速估算 + 行间停顿 + 标签留白。

批量任务 = 分组（右侧「批量」页）
--------
一个分组 = 一批句子 + 一套参数（音色 / 情感 / 权重 / 停顿），可以建多个，
分别处理不同段落或不同角色（旁白、角色A…）。生成时可以只跑某几个分组。
建分组：命名 + 参数 + 范围（当前选中 / 所有未分组的行 / 编号区间）。
建好后参数会写进这些行的行级覆盖值，分组本身记住这批句子，之后可以：
  · 选中本组  · 直接生成  · 编辑（改名/改参数，会重新应用到这些行）  · 删除（不删句子）

分组情况：语音行总数、已分组、未分组，还有「被多个分组同时包含」的句子数
（这些句子生成时只跑一次）。下面两个按钮：
  · 「选中未分组」  = 选中还没被任何分组包含的句子（再点一次取消）
  · 「选中多组重复」= 选中同时出现在两个及以上分组里的句子（数量为 0 时置灰）
每个分组卡片上还有「选中本组 N」——就是选中这一组里的全部句子。
（以前这里有「选中已覆盖 / 选中未覆盖」两个容易绕晕的按钮：一个分组本来就"覆盖"了它自己
 的句子，再按"是否被覆盖"去筛，语义上等于废话。现在统一改成按"组"说话。）

生成（右侧「生成」页）
--------
渲染范围：选中行 / 未生成·需重生成 / 按批量任务（多选）/ 全部行。
进度区：
  · 大进度条（整体，按「已完成句数 + 当前这一句的行内进度」算，右侧显示百分比）
    + 细进度条（当前这一句）
  · 阶段药丸：① 模型 → ② 逐句生成 → ③ 完成，当前阶段高亮、走过的显示为绿色
  · 模型状态行：小圆点 + 文字（未加载 / 加载中… / 已就绪 · steps 25 · fp16 / 加载失败），
    首次生成会先加载模型，这期间进度条变成「不确定」的来回扫描形态
  · 「已完成 3 / 20 句」、「正在生成：台本第 137 行（第 4 / 20 句）」、当前句前 20 个字
  · 已用时间 / 预计剩余 / 平均速度（句每分、每句多少秒）
  · 进度样式可切换：细条 / 流光 / 分段 / 斜纹（记在本地，下次还是这个样式）
可随时停止（当前行结束后停），已完成的行不重跑；关页面、重启服务都不影响。


音效素材库（给标签挂的音效）
====================================
入口：台本页顶栏「🔔 音效素材库」；时间轴页右侧「素材库」面板也有「🔔 音效库」页签。

一、音效库
--------
· 「＋ 上传音效」可多选音频或视频（视频自动抽音轨），统一转成 44.1k WAV，**声道保留**；
· 三种显示方式：列表 / 卡片 / 网格；可搜索；右键更多；
· 每项：名称（点击改名）、时长、采样率、声道、大小、来源 / 处理动作标签；
· 右键菜单：试听 / ℹ 属性 / 挂到选中的标签 / 复制 / 粘贴副本 / 重命名 /
  拷进导入台改一改 / 删除；
· 「复制 + 粘贴副本」= 声音一模一样的两份，各自改名、各自处理，适合做「轻一点 / 慢一点」的变体；
· 删除只是移入 longform/sfx/.trash，已挂到标签的地方会显示「音效已删除」，不会崩。

二、音效预处理 = 素材导入台（去向选「音效库」）
--------
音效不再有单独的预处理面板，统一走「素材导入台」：
点「导入台处理 →」，抽屉切到导入台，顶部「存入」自动选中 🔔 音效库，处理项也换成音效那套。
· 处理项：裁剪时间段 / 去首尾静音 / 降噪 / 淡入淡出 / 响度与音量（归一 + 额外增益 dB）/
  变速（不变调，WSOLA）/ 变调（不变时长，±7 半音）/ 低切·高切 / 反向播放 /
  从歌曲里取（只要人声 / 只要伴奏）/ 采样率·声道（默认都不变）；
· 三个快捷：「短音效」（去静音 + 10/80ms 淡入淡出 + 峰值 -1dB）、
  「环境音」（低切 80Hz + 轻降噪 + 300ms 淡入淡出 + RMS -18dB）、
  「人声提示」（提取人声 + 降噪 + 去静音 + 峰值 -1dB，需要立体声素材）；
· 处理完点「处理并存入音效库」→ 结果直接进音效库（不会在导入台里再生成一堆「处理结果」）；
· 想改一个已经入库的音效：右键它 →「拷进导入台改一改」，原音效保留，改完存回去是新的。

关于视频：音效库允许直接传视频，但**只取音轨**——导入时就抽成 44.1kHz WAV，
库里不保留视频文件。混音、工程导出（rpr/EDL/分轨）读的都是这条 WAV，
所以视频不会影响导出结果，这个功能保留。只是很长的视频（>60 秒）挂到标签上会盖住语音，
导入和处理时会提示你先裁短。

三、标签挂音效（重点）
--------
台本里每个**句间标签**都有「＋ 音效」按钮（工作台卡片里也有）：
· 点它 → 弹出音效选择器：搜名字、▶ 试听、点「用这个」即挂上；再点一次可以换；
· 也可以右键标签 →「🔔 挂载音效 / 更换音效 / 试听 / 移除」；
· 标签编辑弹窗里就是一套完整面板：标签名 / 留白（滑杆+数字）/ 音效（下拉 + ▶ 试听 + 音量），
  下面还会实时显示「这个标签在 ≈x.xx 秒处，音效在这里响」；
· 已挂音效的标签会显示「🔔 名字」，鼠标停上去能看到「标签时间 + 留白」的说明。

**音效出现的位置 = 标签所在时间 + 该标签的留白**
所以「留白 600ms」= 这个标签响完再等 0.6 秒，音效才响；留白 0 = 紧贴标签位置。

四、标签多选与批量改标签
--------
标签行和语音行一样可以勾选，也支持「↑ 往前全选 / ↓ 往后全选」「右键 → 从这一句往前/往后全选」。
选中标签后点「批量改属性」：
· 只选标签时，弹窗里只剩「句间标签」一块：标签名 / 留白 / 音效（—不改— / 移除音效 / 选一个）；
· 语音行和标签一起选时，两块同时出现，各改各的；
· 批量改留白时，挂在这些标签上的音效会一起平移（因为位置 = 标签时间 + 留白）。

五、进时间轴之后
--------
从台本页「保存并进入时间轴」后，挂了音效的标签会在**素材轨**上自动生成一个片段：
· 位置 = 标签时间 + 留白，和台本页说的一致；
· 片段是锁定的（不跟着拖动跑），名字显示「〔标签〕音效名」，开头带 🔔；
· 要挪位置就回台本改留白，或在时间轴里从「音效库」页签手动再插一个；
· 时间轴右侧「标记」列表里，挂了音效的标签也会带一个 🔔。

注意：时间轴用的是「工程副本」。工程建好之后，原台本里再改标签不会回灌到工程，
要到工程副本（左侧列表里带「工程」标记的那个）里改，时间轴才会跟着变。

音色素材库 + 素材导入台（前期准备）
====================================
入口：台本页顶栏「🎙 音色素材库」「🔔 音效素材库」「参数预设」（原来的「音色与预设」已拆成两个库 + 预设）。
三个库现在是同一套版式（都在右侧抽屉里）：
  抽屉头：图标 + 库名 + 一句话说明（这个库干什么、文件从哪来）；
  动作区：主按钮（上传） + 「📥 导入台处理」（带着去向跳进导入台）；
  工具条：列表/卡片/网格 · 搜索 · 刷新 · 数量；
  列表：统一的条目录入点（▶ 试听 / ✓ 应用 / ✎ 改名 / ✕ 删除，右键更全）；
  页脚：给谁用、有什么限制（音色 22.05k 单声道、音效保声道…）。
· 音色素材库：**音色库** +「导入台处理」（去向自动选音色库）；
· 音效素材库：**音效库** +「导入台处理」（去向自动选音效库）；
· 参数预设：命名输入 +「保存当前默认」+ 搜索 + 预设列表（点名字直接应用）。
· 导入台的「处理并存入」下面还有两颗跳转按钮：
    「🎙 去音色素材库」「🔔 去音效素材库」——存完直接去对应的库里用它，
    不用先关抽屉再翻顶栏。

一、导入台是什么（文件流转的唯一出口）
--------
以前有三处都能「处理音频」（素材库、音效预处理、音色库），它们共用同一个面板、靠
「作用域」切换，结果就是「切回素材」时会看到另一堆中间文件，分不清哪些是音色、
哪些是音效、哪些只是临时文件。现在改成一条单向流水线：

    上传 / 拖拽（可批量、多选）
          ↓   一律先落到「素材导入台」（longform/materials，44.1kHz WAV，保留声道）
    勾处理项 →「处理并存入」        （也可以「直接存入」不做处理）
          ↓
    🎙 音色库（22.05kHz 单声道 WAV）    🔔 音效库（44.1kHz WAV，声道不变）

· 导入台里的文件**永远只是中转**，不会出现在两个库里；两个库里的东西也不会出现在导入台；
· 顶部「存入」只决定「处理完去哪 + 用哪套处理项」，**不改变你在看哪个列表**；
· 「存入后把导入台里的源文件移进回收站」默认勾选：勾着导入台不会越堆越多，
  源文件在 longform/materials/.trash 里还能找回；不勾就留着继续做第二种结果；
· 「清空导入台」（右上）= 把勾选的（没勾就全部）移进回收站，有二次确认，不会真删。
· 「♻ 回收站」（右上）：清空/删除过的中转文件都在这里，可以单条「恢复」、勾选恢复或「恢复全部」；
  恢复会按原文件名、原参数（时长/声道/来源/处理动作）放回导入台。回收站清单存在
  longform/materials/.trash/manifest.json，最多留 500 条。

二、导入台里的素材
--------
支持：音频 wav/mp3/flac/ogg/m4a/aac…、视频 mp4/mov/mkv/avi/flv/webm/m4v…
（拖拽或点选，**可多选**，一次导入几十个也行）
· 导入即「抽音频 + 统一成 44.1kHz WAV」；视频自动只取音轨，库里不留视频文件；
· 三种显示方式：列表 / 卡片 / 网格（记在本地）；支持搜索、按类型筛选、全选；
· 每项：名称、时长、采样率、声道、大小，标签显示 视频 / 处理结果 / 处理动作；
· 右键一项：试听 / ℹ 属性 / 勾选 / 🎙直接存入音色库 / 🔔直接存入音效库 /
  ⚡只提取人声 / ⚡净化人声 / ⚡做成音色 / 重命名 / 复制名称 / 从导入台移除；
· 列表里的 🎙 / 🔔 小按钮 = 对「这一项」直接存入当前去向（不勾处理项，只做格式归一）。

三、处理项（两大一键按钮 + 「详细方案设置」）
--------
勾好素材后，处理区最上面是两张方案卡，日常只用这两个：

  🎙 一键做成音色   = 人声分离 → 降噪 → 去首尾静音 → 峰值归一 -1dB → 22.05k 单声道
                     （和原来的「做成音色」预设完全一样，还会先裁前 15 秒）
  🔔 一键做成音效   = Demucs 只取伴奏（instrumental），**其它一律不处理**

每张卡片分两块，分工很明确：

  · 左边的**方框**：勾上 = **只把方案装进下面的详细设置**，播放台和参数立刻跟着变，
    但**不处理任何文件**（用来先看效果、再微调）。两张卡互斥，勾一张另一张自动取消；
  · 右边的**「生成！」**：真正开始处理并入库（按当前界面上的参数跑）。
    没勾过方框就直接点「生成！」，会先把这套方案装好再跑。

没有勾素材时点它们只会提示，不会误跑一整批。

想自己调参数、换去向、或者「不处理直接存入」，展开下面的「详细方案设置」——
原来那一堆勾选框、滑块、快捷预设（短音效 / 环境音 / 人声提示 / 净化人声）都在里面，
默认收起，不再一上来就铺满一屏。

· **分离精度**（Demucs 才有）：快速 1 次 / 标准 2 次 / 精细 4 次随机时移平均。
  越精细越干净，时间也线性变长（30 秒素材：快速约 2 秒、精细约 8 秒，显卡）。
· **分离引擎**：Demucs 高精度（默认）/ 中置提取（快）。装了 BS-Roformer 模型之后，
  下拉里会多出第三项（见下面「BS-Roformer（可选，模型自备）
--------
**入口**：📥 素材导入台 → **滚到最底部**（ffmpeg 状态条下面）并排的两颗浅绿按钮里，
**右边那颗「🧩 模型拓展」**（点一下展开，再点收起）。左边那颗是「高级音频处理台」，
两者挨着，都属于进阶功能 —— 放在最底下是因为它们不该插在「上传 → 勾处理项 → 存入」这条主线中间。

**先判断要不要装**：Demucs 已经够用就别管这一节。只有当你觉得「Demucs 分出来的
伴奏里还留着一层人声、有电音感」时，才值得上 BS-Roformer。模型 275MB（Demucs 才 80MB），
首次加载十几秒，工作台不自带、不自动下载，只做「检测 + 挂载」：有模型就能选，
没有就是灰的，完全不影响现有功能。

顶部状态条里也有一行「模型拓展」，括号里写的就是**当前用的那个模型名**；
右边 ? 直接打开这一节。

■ 这一块接的不是「某一个模型」，是一整套可插拔的后端
  推理后端是 pymss（ZFTurbo/Music-Source-Separation-Training，MIT），模型放 vendor2\roformer\，
  目录里有什么就能选什么，代码不绑定某一个权重。现在能跑：
    · BS-Roformer（bs_roformer）        —— 主力，下面推荐的都是这一类
    · Mel-Band Roformer                 —— 梅尔刻度分带，更细更慢（871MB~1.6GB）
    · BS-PolarFormer / BS-Conformer     —— 同家族变体（权重出了就能用）
    · MDX23C / SCNet / HTDemucs / VR    —— 老模型也能挂进来对照
  所以「只增加了一个 BS 方案」这个说法不准确：加的是一条后端 + 一个模型目录，
  BS 系只是里面最值得用的那一支。

■ 一个模型就够，不用为「提人声 / 去人声」各下一个
  这类模型是「人声 / 伴奏」二分离：一次推理同时给出 vocals 和 instrument 两轨，
  上面选「只要人声」还是「只要伴奏」只是取哪一轨。
  模型库里另有一类「伴奏 / 无人声提取」专用模型，那是给「只要伴奏」再优化一档的，一般用不上。

■ 出处与更多权重（想自己找、自己训就看这几个）
  · 论文：Music Source Separation with Band-Split RoPE Transformer（ByteDance, 2023）
      https://arxiv.org/abs/2309.02612
  · 架构实现：lucidrains/BS-RoFormer（MIT，只有网络定义，不含权重）
      https://github.com/lucidrains/BS-RoFormer
  · 训练框架 + 官方权重发布：ZFTurbo/Music-Source-Separation-Training
      https://github.com/ZFTurbo/Music-Source-Separation-Training
  · 权重清单（按任务查哪个名字）：
      https://github.com/ZFTurbo/Music-Source-Separation-Training/blob/main/docs/pretrained_models.md
  · 社区权重合集（safetensors，用前要转成 ckpt，进阶）：
      https://huggingface.co/AEmotionStudio/roformer-models

■ 推荐哪个（挑一个就行）
  bs_roformer_voc_hyperacev2.ckpt      275MB  推荐，同为 BS-Roformer 里速度最快、综合最好
  BS-Roformer-Resurrection.ckpt        195MB  体积最小，显存紧 / 只想先试试
  model_bs_roformer_ep_368_sdr_12.9628 610MB  经典款，MUSDB 人声 SDR 12.96，速度慢一倍
  （Mel-Band Roformer 系 871MB~1.6GB 更重更慢，一般没必要）

■ 第 1 步：装推理后端（必须，一次就够）
  模型只是权重，真正跑推理的是 pymss（开源，MIT）。整合包根目录执行：
      runtime\python.exe -m ensurepip --default-pip
      runtime\python.exe -m pip install pymss
  用包自带的 Python，不污染系统环境；torch 若已满足要求不会被重装。

■ 第 2 步：下模型（两种，选一种）
  A. 一条命令（推荐，会自动连 yaml 一起下）：
      runtime\python.exe -m pymss.cli download bs_roformer_voc_hyperacev2 ^
          --model-dir vendor2\roformer --source modelscope
     --source 可选 modelscope / huggingface / hf-mirror。
  B. 手动：去下面任一仓库，进 vocal/vocal_extraction/，把**同名**的 .ckpt 和 .yaml
     两个文件一起丢进 vendor2\roformer\（可以建子文件夹）：
        https://huggingface.co/baicai1145/pymss          原始仓库，国内常连不上
        https://www.modelscope.cn/models/baicai1145/pymss 国内镜像，一般更快
     文件名别改；小于 5MB 的文件会被当成没下完的半截文件忽略。

■ 用起来
  · 导入台 →「BS-Roformer 模型」折叠块 → ⟳ 重新检测 → 状态行变绿后，
    「提取人声 / 从歌曲里取」的引擎下拉里会多出「BS-Roformer（模型名）」；
  · 顶部状态条也有一行 BS-Roformer：就绪显示模型名，缺后端会写「缺推理后端」，
    没有就写「未启用（可选）」，右边 ? 直接跳到这份说明；
  · ▶ 试跑一次：3 秒合成音实跑，确认「模型 + 后端」能跑通（只看链路，不评判音质）；
  · 降级：处理链是「BS-Roformer → Demucs → 中置提取」，选的先试、挂了自动往下退，
    结果标签写「（替代）」，不会因为模型配坏让一条素材整条失败；
  · 📂 打开模型目录：目录不存在会自动建；想放别处设环境变量 LF_ROFORMER_DIR；
  · 中间文件在 longform/roformer_work/，可随时删；vendor2\roformer\ 里的权重
    不会被打进补丁包。

■ 值不值（本机实测，RTX 5070 Ti Laptop，真模型）
  一首歌的 30 秒片段：人声轨与伴奏轨互相漏音的相关性 0.04（Roformer）vs 0.08（Demucs），
  即伴奏侧残留少一半；速度都是 30 秒素材约 2 秒（1.8s / 1.6s），首次加载 20s / 5s。
  换成纯说话的素材，两者差距只剩 0.3dB 量级 —— 所以建议拿自己的素材各跑一遍再决定。

【DnR（可选，模型自备）—— 唯一能把「纯音效」单独拿出来的】
  和 BS-Roformer 不是一类：BS 是「人声 / 伴奏」二分，DnR 是「对白 / 音乐 / 音效」三分。
  **只有它把「音效」单独列一轨**，所以它在导入台里的定位是分离方式里的「只要音效」那一档。

■ 它能干什么、不能干什么（本机实测，逐段跑）
  · 舔耳 / 摩擦 / 环境声 → **Effects 轨**：118 秒舔耳切 12 段，10 段由 Effects 主导，
    平均 −1.0 dB、标准差 1.5 dB —— 稳；
  · 喘息 → **Speech 轨**：同样的做法，12 段里 11 段归人声，Effects 稳在 −15～−25 dB。
    喘息有声带振动，在模型看来就是人声，**抠不出来**；
  · 台词和喘息混在一起时更分不开（同一段里两者都在 Speech，差 0.3 dB）。
  · 结论：**用它抠纯音效，别指望用它分开「说话」和「喘息」。**

■ 装法
  · 推理后端和 BS-Roformer 共用 pymss，装过一次就不用再装；
  · 下模型（149MB，一条命令）：
      runtime\python.exe -m pymss.cli download model_bandit_plus_dnr_sdr_11.47.ckpt ^
          --model-dir vendor2\dnr --source modelscope
  · 模型目录是独立的 vendor2\dnr\（想放别处设 LF_DNR_DIR）；放好后在
    「模型拓展 → DnR」里点「⟳ 重新检测」，两个下拉里就会多出 DnR / 只要音效。

■ 用起来
  · 导入台「提取人声」卡：勾上 → 分离方式选「只要音效（DnR）」→ 引擎选 DnR → 开始处理；
  · 结果标签会写「音效 + DnR」，入库后能在素材库里按标签找；
  · **不参与降级**：「只要音效」这一档如果模型没装，会直接报错并提示去装，
    不会悄悄退回 Demucs（Demucs 没有音效轨，退过去等于白跑）；
    其他模式（只要人声 / 只要伴奏）里 DnR 会排进降级链：DnR → Demucs → 中置提取；
  · 速度：比 BS-Roformer 慢约 6 倍（它是单声道模型，左右声道各跑一遍）。
    72 秒素材约 33 秒；不急的时候用，别当默认引擎。

■ 模型拓展面板（v0.34 起）
  「模型拓展」里每个模型是一个可折叠项，标题行右边有状态标签
  （已就绪 / 缺后端 / 未安装），不展开也能看出装没装。展开才是说明、目录、命令、试跑。

置顶（导入台 / 音色库 / 音效库通用，可置顶多个）
--------
· 每条素材行末尾有个小图钉 📌（没置顶时很淡，鼠标移上去才亮），点一下置顶，
  再点一下取消；右键菜单第一项也是「📌 置顶 / 取消置顶」。
· 置顶只改排序、不动文件：置顶的排在同组最前面，**后置顶的更靠前**；取消后回到原位。
· 可以同时置顶多条；导入台、音色库、音效库三个地方共用同一份排序，
  时间轴页右侧的素材面板（音效库 / 音色库 / 导入台）看到的顺序也一样。
· 排序记在各库的 index.json（pin 时间戳），备份 / 迁移时会跟着走。

人物标签（跨台本的关键机制）
--------
**先分清两个「标签」**：
· 工程里的「标签」= 句中 / 句间的时间点标记，只在当前工程里生效；
· **人物标签** = 一个跨台本的人物库，决定「这个角色用哪个音色」。两者互不相干。

为什么需要：有声书 / 多章节音声里，同一批角色会反复出现。智能导入能把台词按
「阿澈：…」分成角色组，但分组只是一个名字 —— 每次导入都还得挨个挑音色。
人物库把这层对应关系记住：**打一次，以后每章都自动套**。

■ 一个人物是什么
  · **一个人名标签**（唯一）：阿澈；
  · **多个别名**（可选）：澈哥、小澈 —— 不同章节写法不同也能认；
  · **多个属性标签**：傲娇 / 冰山美人 / 青年音 / 旁白（只是描述，方便自己看）；
  · **绑定的音色**：这个角色用谁的声音。
  一个人物只能有一个人名标签，属性标签可以很多；音色也可以只打属性标签而不绑人物。

■ 在哪设置
  ⚙ 设置 → 最上面「**人物标签**」块（在「时间轴与工作台」之前，跨台本、跨工程）。
  设置面板现在**四块各自可折叠**：人物标签 / 时间轴与工作台 / 混音导出默认 / 参数预设，
  点标题开合，折叠状态会记住（下次打开还是你上次合起来的样子）。
  人物标签默认展开，其余默认收起；「保存设置」固定在面板最下面，折叠也看得见。
  · 「＋ 新建人物」：填人名 / 别名 / 属性标签 / 绑定音色；
  · 「从当前台本分组新建」：列出这个台本里**还没收录**的分组名，勾选批量建
    （默认全选），建完逐个绑音色即可；
  · 列表每行：人名 · 又称 · 属性标签 · 音色下拉（直接改，立刻保存）· 当前台本用了几句 · ✎ / ✕；
    用量显示成橙色，表示这几句还没用上这个音色（点下面的「智能识别人物」）；
  · 搜索框可搜人名 / 别名 / 属性标签；
  · 删除人物**不动音色、不动台本**，只是以后导入时不再自动对上。

■ 匹配顺序（重要）
  1. **人名**（含别名）：分组名完全一致 → 用它绑定的音色；
  2. 去括号 / 拆前缀后再对人名：「阿澈（低声）」「第一章 · 阿澈」也能认，标「≈ 近似」；
  3. 人名都没命中，才看**音色上的属性标签**（🎙 音色素材库 → 🏷）；
  4. 还不行 → 不套，留给你手动处理。
  人物认出来了但**没绑音色**时不会乱套：单独列在「人物认出来了，但还没绑音色」里，
  选一个音色点「绑定」就行。

■ 智能导入时
  · 预览顶部：「🧠 认出 N 个角色能对到音色：阿澈 → 青年音A」；
  · 每个分组标题右侧：👤 音色名（人物）/ 🎙 音色名（属性标签）/ 👤 未绑音色；
  · 勾「导入时按人物自动设音色」再导入，这一组句子直接用上对应音色。
  · **只改音色**：情感、停顿、采样一律不动 —— 这些随台本和情绪变，自动套只会添乱；
  · 这个勾是**全局设置**（设置 → 人物标签），默认开、改了所有台本都生效，
    不用每章重新勾；导入预览里仍可单次取消。

■ 已经导好的台本
  ⚙ 设置 → 人物标签 → **🧠 智能识别人物（套到当前台本）**：
  按当前台本的分组名重新对一遍。结果窗分三段：
  · 已对上：角色 → 音色，标 👤 人物 / 🎙 标签，显示影响几句；
  · 人物认出来了但没绑音色：选音色点「绑定」，加完自动再识别；
  · 没对上：选音色点「＋ 建人物」，这个角色就进人物库了，下次导入自动认
    （下拉里是完整音色名，长的名字也不会被截半——鼠标停一下还能看全名）。
  已经单独指定过音色的句子默认「保留」；想一起覆盖点「⟳ 连已指定的音色也一起覆盖」。

■ 音色上的「属性标签」怎么用
  🎙 音色素材库 → 每行末尾 🏷（右键「加属性标签…」）→ 从标签库里挑，或直接打新的。
  · 它**不改文件名、不进音频**，删光即取消；
  · 列表上方有标签筛选条（🏷 不限标签 / 各属性），搜索框也匹配标签；
  · 属性标签只在「人名没命中」时参与匹配，所以同名属性挂在多个音色上时，
    按「置顶 → 新的优先」取第一个；
  · 想固定「阿澈 = 这个音色」，别靠标签 —— 去人物标签里建「阿澈」并绑定它。

■ 标签库（设置 → 人物标签上方）
  🏷 属性标签库：27 个预设（傲娇 / 冰山美人 / 温柔 / 病娇 / 少年音 / 旁白…），
    可以在输入框里加任意新标签，点 chip 上的 × 删掉不要的。
  🔔 音效标签库：27 个预设（音效1-3 / 摩擦音 / 呼吸 / 雨声 / 关门 / BGM…），
    这些就是插入句中 / 句间标签时那一排候选。
  · 删内置标签只是「隐藏」，重新加一个同名就又回来了；删自定义就是真删；
  · **删标签不会动已经打在音色 / 人物上的标签**，只是候选里不再出现。

■ 音色优先级（设置里也写着）
  ① 这一句单独指定 → ② 人物绑定音色 → ③ 音色上的属性标签 → ④ 台本默认。
  人物识别会把命中的音色写成「这一句的音色」，所以打开属性面板看到的是它而不是默认值，
  面板顶部会标「当前生效音色 · 来源」；把这一句改回「跟随台本默认」就会重新走 ②③④。

■ 人物标签 ≠ 音效标签
  · 人物标签：人名（唯一）+ 别名 + 属性标签 + 绑定的音色，决定「谁用哪个声音」；
  · 音效标签：句中 / 句间那些「音效1 / 呼吸 / 雨声」，决定「这一处响什么、留多久白」。
  所以标签弹窗标题都写「句中音效标签 / 句间音效标签」，和人物库不是一回事。

■ 多章节的建议用法
  第一本书建好人物库（5～10 个人物 + 音色）之后，后面每一章：
  导入 → 看预览里的 👤 提示 → 直接导入 → 需要时补一句「从当前台本分组新建」。
  新角色只在第一次出现时需要建一次。

高级音频处理台（长音声 / ASMR 专用）
--------
入口：📥 素材导入台 → 滚到最底部、**左边那颗浅绿的 🎛 高级音频处理台**（新开一页）；
顶栏也有一颗（「🎛 高级音频处理台」，和「📥 素材导入台」挨着，不进抽屉也能开）。
也可以直接开 `/sfxbench`，用第 1 张卡的「＋ 直接加入」把本机文件拉进来。
勾了素材的话会把它带过去。

这一页也有**日间 / 夜间**：右上角「🌙 夜间 / ☀ 日间」，和工作台、时间轴共用同一个开关
（`localStorage["lf.theme"]`），在哪儿切都是一起变；波形、导航条会按新配色重画。

干的事：把一整段音声**按需要拆开**（去人声留伴奏 / 去伴奏留人声 / 原样），
再把声音**按事件或字幕切成一段段音效**，挑一部分存进音效库 / 音色库 / 导入台，
或者**按字幕对位**直接写进时间轴工程的对应位置。

页面分左右：左边 6 张参数卡（每张右上角有 **?**，点开逐条解释这一块和每个选项），
右边从上到下是 **导航窗 → 播放头条 → 原音轨 → 处理后 → 字幕轨（载入字幕后才有）→ 播放条 → 片段列表**。

① 选素材（第 1 张卡）
  · 「＋ 直接加入」：选本机音频/视频，先存进导入台，再自动选中；
  · 也可以把文件直接拖到素材列表上；从导入台里挑仍然可以；
  · 长音声建议先在导入台里裁出要处理的那一段（几十秒到几分钟）——
    分离是整条跑的，40 分钟的整轨去人声要好几分钟。

② 处理（可选，第 2 张卡）
  这一步不是必须的：纯音效素材选「原样」，直接进切分。三档：
  · **留伴奏**：去掉台词人声，留环境 / 动作 / 音乐。切音效最常用；
  · **留人声**：去掉伴奏和背景乐，只留人声。切喘息、气声、耳语这类「是人声但没台词」的素材；
  · **原样**：不分离，直接在原音上切。分离反而更差时也选这个。
  引擎：BS-Roformer（装了模型才可选，最干净）/ Demucs（内置）/ 中置提取（最快）。
  「精度」只对 Demucs 有意义；「残留抑制」只影响伴奏里的人声残影（0–15% 通常够）。
  点「② 去掉人声并载入 / 去掉伴奏并载入 / 直接载入」后等它跑完（3 分钟素材显卡约 30 秒）。
  结果会落盘成作业文件，之后改切分参数**不会重跑分离**。作业只保留最近 8 个。

③ 切成片段（第 3 张卡，这一步随便调，几毫秒）
  这张卡在准备之前是灰的（还没有作业可切），处理完就会亮起来，之后只改参数随时重切。
  · 切法：
      - 按静音间隔（默认）：最稳，适合对白/动作音之间有停顿的素材；
      - 按字幕间隔（对位进工程用这个）：字幕区间是「在说话」，取补集就是音效候选区；
      - 先减稳态背景再切：雨声、风扇、空调这种连续背景底下的事件才会浮出来；
      - 按起始点：节奏型/打击类更贴（谱通量）。
    后两种如果减完什么都没剩下，会自动退回「按原信号切」并说明原因，不会甩你一个空列表；
  · 最小间隔：小于这个长度的停顿不切（越大越会把相邻声音并成一段）；
  · 最短片段：短于这个的直接丢掉（滤掉咔哒杂音）；
  · 门限 dB：越大越严格（只留明显的），越小切得越碎。默认 10；
  · 前后留白：每段往外扩一点，避免把起音/尾音切掉。默认 0.03 秒。

④ 三条轨：原音 / 处理后 / 字幕
  · **原音**：原素材本身，只读，用来 A/B 对照。载入后跟「处理后」共用同一个播放头；
  · **处理后**：处理后的那条，可编辑（见 ⑥）；
  · **字幕**：载入字幕之后才出现，每句一块；点一下 = 跳到那句，悬停出完整台词。

  每条轨的**左上角**就是它的控制区，一眼能看出「这条现在什么状态」：
  · **状态胶囊**：待命 / 播放中 / 已静音（不是靠按钮图标猜）；
  · **▶ / ⏸**：只放这一条 —— 另一条自动静音；正在放时按钮变 ⏸，再点暂停；
  · **🔊/🔇**：静音这条 —— 可以「只听处理后」「只听原音」，也可以两条一起听；
  · **音量滑块**：两条轨各自独立；后面的小数字是当前播放头位置；
  · 字幕轨同样有播放 / 上一条 / 下一条。

  更上面两条：
  · **导航窗**（细条）：整条的缩略波形 + 视窗方块 + 播放头。点一下跳过去、拖方块平移、双击看全长；
  · **播放头条**：带刻度的独立一条，只干「拖播放头」一件事。按住拖就是改位置（会先暂停，松手后本来
    在播就接着播）；它和波形上的圈选 / 拖边界 / 平移分开，不会抢手势。双击看全长。

⑤ 载入字幕（第 4 张卡，做对位时必需）
  · 三种来源：拖入 .srt / 点「选 .srt 文件」/ 直接粘贴；或者**「或从台本」**直接选工作台里的台本 ——
    它从 SRT 导入时记下的时间码会原样搬过来，不用再导一遍同一个文件；
  · 编码自动认：先按 UTF-8 严格解，失败退 GBK / GB18030 / Big5；
  · 载入后会出现**字幕轨**：青色块，两端有竖线（就是这句的起止），块里写着条号；
    点块 = 跳到那句，鼠标停上去会浮出「第 N 条 · 起止 · 时长 + 完整台词」；
  · 字幕轨标题行有 ◀ ▶ 上一条 / 下一条；第 4 张卡里还有「→ 跳到下一条字幕」；
  · 载入后「切法」自动切成「按字幕间隔」——这是本页最准的一种切法。
    按静音间隔切只能判断「有没有声音」，而台词和音效都有声音，分不开。

⑥ 直接编辑 + 片段处理（处理后那条轨）
  · **拖空白处**：圈出一段新片段（绿色预览框），松手即生效；
  · **拖片段两端**：改起止（光标变成 ↔）；**拖片段中间**：整段平移；
  · **点空白**：把播放头放到这里；**点片段**：选中并试听；
  · 工具条：`▭ 标记` `✂ 切分`（在播放头处切选中/所在的段）
    `⤵ 合并`（选中多段合成一段）`✕ 删除` `↺ 撤销` `↻ 重做` `⚙ 处理选中` `全选` `反选`；
  · **⚙ 处理选中**：把导入台那套音频编辑搬进来了 —— 首尾静音 / 淡入淡出 / 音量 /
    变速 / 变调 / 标准化 / 降噪 / 高低通 / 反向。勾几条就套几条，**选多段 = 批量套同一套参数**；
    每段各记各的处理，行上出现 **FX** 小标（点开改、右键清）。「试听第一条」走服务端同一套算法，
    听到的就是入库/进工程的那一份；变速、变调、首尾静音会改变长度，按处理后的实际长度写；
  · **撤销**最多 40 步，拖边界、平移、合并、删除、切分、批量命名、片段处理、**重新切分**、
    **恢复方案**都能退；重做（Ctrl+Shift+Z）把撤掉的再放回来；
  · 列表每行：勾选框 / 序号 / 名字 / 起止秒数（**可直接改数字**）/ 时长·电平 /
    ▶ 试听（再点变 ⏸）/ ✂ 拆分 / ⤵ 合并下一段 / ✕ 删除；行高固定，单选多选都一样高；
  · **多选**：点行 = 只选它，`Ctrl/⌘+点击` 加减选，`Shift+点击` 选一段范围；
    选中态同时就是「要入库 / 要插入」的那批，底部会写「已选 N 段 · 合计 X 秒」；
  · **右键**：试听 / 循环 / 只放原音 / 切分 / 合并 / 只保留这一段 / 起终点设为播放头 / 重命名 /
    ⚙ 处理 / 清除处理 / 🎙 存入音色库 / 🔔 存入音效库 / 删除。

  快捷键：空格 播放/暂停 · ←/→ 播放头 ±50ms（Shift ±10ms）· S 切分 · M 合并 · Del 删除 ·
  Ctrl+A 全选 · `[` `]` 把选中片段的起/终点移到播放头 · Esc 关菜单。

⑦ 处理方案（第 5 张卡，保存 / 恢复）
  切分参数是试出来的：门限调到刚好之后，还想试下一组，就得先把这一组记住。
  · 给当前状态起个名字（留空自动按时间命名）→「保存」。
    存的是「处理方式 + 引擎 + 切分参数 + 手工片段（含各自的处理参数）」，最多 20 条，存浏览器本地；
  · 「恢复」：参数和片段一起回来，当前片段先进撤销栈；方案记得它来自哪个素材，
    换了素材恢复时会提示「只搬参数与清单，试听 / 插入仍需重新准备」；
  · 重新切分 / 重新准备时如果检测到手工改动，会先弹确认窗；「自动存一份方案」默认勾着。

⑧ 挑得更快：缩放 / 命名 / 查重
  · 波形可以放大：播放条上的 − + 全，或者**滚轮**（以指针为中心）、**拖动平移**、双击回全长；
  · 「✎ 按字幕命名」：整批写成「第N条后 / 第N条内 / 片头」，之后再手改个别的；
  · 「⧉ 查重」：同一段声音在原片里出现十几次很常见，入库一次就够。
    查到后重复行压暗标「重复」，点「删掉重复」只留每组第一个（只影响这次导出，不动原素材）。

⑨ 存入：音效库 / 音色库 / 导入台（第 6 张卡上半）
  · 「存入」选目标库 →「📁」挑文件夹（没有就现场建，也可以不归档）→「存入选中片段」；
    底部按钮会写「存入音效库（3 段）」，勾几段存几段；
  · 右键某一段可以直接「存入音色库 / 存入音效库」，不用改上面的目标；
  · 切片会带上来源素材名和处理链（例如「音频处理台 · Demucs + 变速」），事后在库里看得出怎么来的；
  · **默认给这一批建一个文件夹**：勾着「为这一批新建文件夹」时，文件夹名 = 素材名，
    这批几十段全进同一个夹子（同一素材分几次存也会进同一个），事后一眼能找到；
    想放别处就取消勾选，点 📁 自己挑（没有的文件夹现场就能建）；
  · **自动编号按这一批的总数补位**：留空名字时，9 段是「原音_1…原音_9」、120 段是
    「原音_001…原音_120」、1005 段是「原音_0001…原音_1005」——位数固定跟着总数走，
    所以按名字排序永远是正确顺序（以前固定两位，第 100 个叫「原音_100」，
    按名字排会插到「原音_10」后面，剪映 / PR 合并素材就乱在第 100 个）；
  · 一次存几百上千段也不会越来越慢（索引整批只读写一次：120 段约 2 秒、1005 段约 5 秒）；
  · 存进音色库时统一转 22050 单声道（模型只认这条线），存音效/导入台保留原采样率与声道。

⑩ 按字幕对位进工程（第 6 张卡下半，推荐流程）
  目标：原音里「第 12 句说到一半响的关门声」，换音色重新生成后，它仍然跟着第 12 句。

  ▍怎么算的（v0.31 起）
  先判「这个音效落在**第几条字幕**」，再去工程里找**同一条字幕**对应的那句，按句内相对位置放进去。
  所以整句变长变短都没关系，音效跟着那句话走；两句之间的空档按前后句边界插值；片头片尾 1:1 平移。
  预览顶部会写「字幕对位：按序号，43/43 条对上」；如果载入的字幕和工程对不上，会明确警告
  （条数/文本不一致 → 只能按绝对时间换算，位置可能偏）。

  ▍四步走（照这个顺序最不容易错）
  1. **先把工程的句子定下来**：换音色 / 改文本 / 增删句都在这之前做完，重新生成一遍；
  2. **回时间轴刷新一次**（重新打开工程或点刷新），让片段的起止跟新音频对齐；
  3. 处理台第 4 张卡**载入跟素材同一版的字幕**（原片素材 → 原片 srt）；
  4. 「🔎 对位预览」逐段看「第几句 / 句内 +几秒」，没问题再「写入工程」。

  ▍一条规则：字幕要跟「素材」同一版（v0.32 明确）
  · 素材是**原片 mp3**（绝大多数情况）→ 载入**原片那份 srt**；
  · 素材是**工程导出的混音** → 载入**工程字幕**（「或从台本」读出来的就是这份）；
  · 为什么不能混：载入的字幕决定「这个音效算第几句」，素材的时间码决定「它在第几秒」。
    两者不是同一版，句子就整体错位 —— 实测 13 句里能错 10 句。
    （上一版这里写的是「用工程自己的字幕」，对原片素材是反的，已改正。）

  ▍「素材时间」保持「自动」就行
  系统拿素材总长比「载入字幕的末尾」和「台本里的原片时间末尾」，谁近算谁的：
  · 接近字幕末尾 → 按字幕序号对位（换音色变长变短都不会串句）；
  · 接近原片时间末尾 → 直接用台本里的原片时间码；
  · 两个都远 → 素材/字幕多半载错了，会明确警告。
  预览顶部写判定结果，例如「字幕对位：按序号，13/13 条对上 · 素材时间：自动·按载入的字幕」。
  下拉里也能手动指定（原片 / 跟载入字幕），但一般不用动。

  ▍实测（催眠红茶-片段测试2，13 句 / 原 71 秒 → 换音色后 81 秒）
  每句在 30% 和 70% 各切一个测试音效，共 26 段：**26/26 全部落在对应句内，
  句内相对位置保持 0.30 / 0.70，一分不差**。单句最长变 2.94 倍、最短 0.45 倍也一样。

  ▍注意事项（这几条踩了就会错位）
  · **别动句子结构**：对位靠「第几条字幕 ↔ 第几句」，中间插一句 / 删一句，后面的全错一档；
  · **别动字幕**：不要在台本里改组名以外的东西去「顺手修字幕」，尤其是删掉某句的 t0/t1；
  · **别拿工程导出 srt 当原片字幕**：那份是成品时间（0 秒起、按新音频排的），
    拿它当"原片时间"会把音效整段前移/后移；
  · **改完句子要刷新时间轴**：不刷新的话，工程里记的还是旧片段长度，算出来的目标时间对不上画面；
  · **整句被拉长/压短超过 30%**（预览里标红）：句内位置必然被拉伸，这类句子写完建议再手拖一下；
  · 写进去的是**新的素材片段**，原音轨不动；不满意可以在时间轴上删掉重来。

  · **⚡ 一键全流程**：用工程自己的台本载入字幕 →（没处理就先按第 2 步跑）→ 按字幕切分 →
    对位预览。你只在预览窗里点「写入工程」，然后「打开时间轴看结果」——**这是最省事也最不容易错的路**；
  · 其余四档换算保留：跟句子起点（老算法）/ 按全片比例（环境音）/ 吸附句边界（说完才响）/ 不做换算（接末尾）；
  · 只有「从字幕/时间码导入」的台本才有原时间；没有时会明确提示，手打台本用「不做换算」；
  · 「⤓ 清单」导出 CSV（序号/名字/起止/时长/电平/来源），带 BOM，Excel 直接打开不乱码。

几处会自己提醒你的地方：
· **留伴奏后只剩 −20 dB 以下**（红框）：这条素材几乎全是人声，伴奏轨是空的，
  别在这儿白挑 —— 把处理方式改成「原样」，或改成「留人声」；
· **留人声后几乎听不到人声**：说明这条素材本来就不是人声为主，换「留伴奏」或「原样」；
· 字幕之间没有够长的空隙 → 说明字幕覆盖率太高（整条都在说话），按字幕切不出音效，
  调小「最短片段」再切，或改用按静音间隔；
· 对位预览里大量「压缩超过 ±30%」→ 中文句子和原音长度差太多，位置只能作参考，
  写完在时间轴上微调；
· 作业只保留最近 8 个，过期再点会提示「重新准备」（这是常态，不是出错）。

小提示：
· 切出上千段说明门限太低或最短片段太短 —— 那不是「挑音效」，是切碎了；
· 想反过来（把成品音效再拼回去）不需要这一页，直接在时间轴里拖素材轨；
· 这一页和 BS-Roformer 模型都不在基础包里：页面走「增量补丁」，模型单独下
  （没装模型时引擎下拉里 BS-Roformer 会标灰，用 Demucs 也能干，只是没那么干净）。

能力与依赖
--------
· 项目 bin/ffmpeg.exe（随包内置，约 84MB）→ 视频导入、m4a/aac 解码都靠它；
  删掉它也能用，只是不能再导入视频（音频走 soundfile，不受影响）。
· 人声分离是**DSP 中置提取**，不需要下载模型、几秒钟出结果：
  人声居中 + 伴奏立体声时效果好；如果伴奏本身也在中间（很多流行歌混音如此），会有残留。
  想要更强分离选「Demucs 高精度」：按人声/鼓/贝斯/其它四轨分离，伴奏也在中间也能分开。
· 三个目录各管一摊（备份时一起拷走就完整）：
    longform/refs/       音色（22.05kHz 单声道 WAV，喂模型）
    longform/sfx/        音效（44.1kHz WAV，声道不变）
    longform/materials/  导入台中转文件（44.1kHz WAV，可随时清空）
  三个目录各有一个 index.json；删除只进各自的 .trash，不真删。


导出（右侧「导出」页）
--------
提示：每个导出选项旁边都有「?」按钮，点开是这个选项的用途与对音质/体积的影响说明。
【单句导出】每行右侧「⤓」→ 弹窗里可以选格式（WAV / FLAC / MP3 / OGG）、位深或质量、
  采样率、声道，并实时显示这一句的预计体积；文件名不用带扩展名，会按格式自动补。
  声道默认**立体声**（和拼接导出、ZIP 一致）；想要小一半体积再选单声道。
【单句批量导出（ZIP）】沿用上面的「格式 / 音质 / 采样率 / 声道」设置（面板上会写明），
  打包出来的就是对应格式（例如选 FLAC，ZIP 里就是 .flac）。
  序号按**行数**补位（最少 4 位：0001…1005），一万行以上再多一位 ——
  保证按名字排序时顺序永远对（不然 10000 会排到 1000 前面）。
【导出音频】拼接成整条音频（全部行 / 仅选中行），附 .srt 与 .timeline.json
  格式：WAV(16/24/32bit 浮点) · FLAC(16/24bit) · MP3 · OGG
  音质：WAV/FLAC 选位深；MP3/OGG 选质量档（内置编码器，码率上限较低，需要高保真选 WAV/FLAC）
  声道：立体声（默认，双声道）/ 单声道（体积减半）
  时段：填「开始/结束」秒就只导这一段（留空=整条）；「整条」一键清空，
        「选中行范围」把时段自动填成选中行的首尾
  面板下方实时显示：内容总长、本次导出时长、句数、**预估文件大小**（导出后还会给出真实大小与码率）
  单句批量导出 ZIP（序号_文本 / 只有序号 / 只有文本 + 前缀）
【导出文本】Markdown / 纯文本 / **SRT 字幕**，三个开关：带时间戳 / 附加信息 / 含标签
  · SRT 的时间来自「每行的实际时长」：已经生成过的行用实测，没生成的行按字数估
    （语速取整篇实测，冷启动 3.5 字/秒），行间停顿也算进去；
  · **所以这个文件在全部生成完之后才有压片价值**；没生成就导，得到的是一版大致对位的字幕。
    按钮下面写了这句，导出结果里还会补「其中 N 行还没生成语音」；
  · 导出音频（【导出音频】）时本来就会附一份同名 .srt；这个按钮是不导音频、只要字幕时用。
【历史成品】所有导出文件都在这里

试听有关的几条规则：
· 顶栏「⏹ 停止播放」（或按 Esc）会停掉所有正在响的音色 / 音效 / 试听；
· 关掉素材库抽屉、关掉弹窗，里面正在试听的会自动停；
· 同一次只会有一个在播：点了音效再点音色，前一个自动停，不会叠在一起。

筛选（编辑区上方「筛选」这一行）：
· 「全部状态」里新增「有句中标签 / 无句中标签」，专门挑出插了句中标签的句子；
· 右边还有「只看句中标签」按钮，点一下切换、再点取消（和状态筛选联动）。
  注意：句中标签是「句内标记」，只用于导出/时间轴标注，不改变音频。

顶栏右侧「🌙 夜间 / ☀ 日间」= 夜间模式开关，和主界面、时间轴页三页共用一个记忆键，
在任一页切换，其它已打开的页面会立刻同步。

左侧「我的台本」标题右边的「⋯ 更多」是一个下拉菜单，集中了常用操作：
  新建台本 / 导入台本 / 刷新列表
  当前台本：新建副本（含音频）/ 导出 Markdown / 导出纯文本 / 回到导出面板
  显示：隐藏或显示「工程」副本（记在本地）、台本统计（源台本数、句数、字数、已完成数、工程数）
单个台本卡片右侧还有一个「⋯」，是对这一本的 重命名 / 新建副本 / 导出 / 删除。

时间轴工作台（台本页顶部「时间轴」按钮，或 /timeline?sid=<台本ID>）
====================================
把生成好的语音按真实时长排到时间轴上，插素材、调位置，最后导出成品或工程文件。

--------

中：时间轴画布　右：片段属性 / 素材库 / 标记（三块同级，见下）
底：播放监视（左）+ 导航窗（右）——导航窗已把「整体预览」和「导航」合成一个窗格：
  分轨缩略图 + 标记竖线 + 视口红框 + 播放头；点视口外定位播放头并把视图移过去，
  拖红框平移，滚轮缩放，双击回全览。
· 主题：默认浅色；顶栏「🌙 夜间 / ☀ 白天」按钮切换。**主界面 / 全能音声工作台 / 时间轴三页共用
  同一个记忆键 lf.theme，任一页切换其它页会立即跟着变**（同浏览器多标签实时同步，不用刷新）。
  顶栏有版本徽标（v21）。
· 前端资源已设为不缓存：改完页面刷新即生效，无需清缓存。
· 播放引擎：用浏览器原生 audio（每片段一个），稳定出声；音量/淡入淡出实时跟随，变速跟随。
  （倒放功能已移除：原生播放器无法可靠表达倒放，去掉以免误操作。）
· 轨道分组：音声轨在上、素材轨在下，两组之间隔开；音声轨组下方有「新建音声轨」按钮，
  素材轨组下方有「新建素材轨」按钮。轨道多时左侧控制台可滚动浏览（鼠标滚轮）。轨道数量不设上限。

  左右声道平衡、静音/独奏。顶部「🧹 清理空轨」一键删除没有片段的空音轨（每类保留一条）。
· 裁剪：选中片段后拖它**左/右边缘**即可裁剪（剪映同款），拖中间是移动。
· 裁剪会显示原始长度的**半透明虚线幽灵块**（被裁掉的部分），幽灵部分不参与重叠判定。
· 属性里的「源内起点」= 从素材文件的第几秒开始用。改它时**幽灵块左边界和片段右边界都不动**，
  只有可见部分变短（等价于从头部裁一刀）。
· 所有拖动条（片段音量/声像/速度/淡入淡出、音轨音量、音轨详情里的音量与声道平衡）
  靠近默认值会自动**吸附到原点**（100% / 居中 / ×1.00 / 0s），双击滑块直接复位；
  片段属性底部还有「恢复默认」一键还原全部属性。
· 重叠：把片段拖到同轨另一段上并**保持 0.5 秒**，会先找同类别的**空白音轨**放进去；
  没有空白轨才新建（按拖拽方向放在上/下方）。
· 片段颜色：蓝色=已生成　橙色=需重生成（有旧音频，可看波形，但不会进混音）
  虚线灰=未生成（占位，长度按字数估）
· 标签全部变成标记点（吸附点）：句间标签在行间空档，句中标签按字数比例落在句内。
  标签不作为独立内容占音轨，只作「吸附点」——鼠标进入标签垂直线附近（约窗口宽度 10%）才渐显
  插入提示，移开就渐隐消失；只在「素材轨 + 该位置没有片段」时出现。在该位置点一下即可插入音效素材。
· 标记列表每行右侧的「＋♪」、悬窗里的「＋ 插入素材」，打开的**都是同一个选择器**：
  默认停在「🔔 音效库」，也可以切「本工程」挑一条临时素材，支持搜索、双击直接插入。
  以前这里只列本工程目录，刚在导入台存进音效库的东西根本看不到，容易误会「存了没生效」。
· 右侧栏是三块**同级分区**（同一套卡片样式：彩色圆点 + 标题 + 数量 + 折叠箭头）：
    最上面是 **片段属性**（选中片段就要第一眼看到），下面依次 **素材库** / **标记**。
  三块都能单独折起来，互不嵌套。**整栏可以滚动**：属性面板展开把下面的分区顶下去时，
  直接滚右栏就行（以前标记区是弹性高度，被属性面板一挤就压成 0 高，看着像"没有了"）。
  选中片段的瞬间，右栏会自动滚到属性区顶部，不用先找。
· 底部预览窗格**高度固定**（默认 100px，不随播放内容变化）。窗格上沿有一条拖拽条：
  上下拖可以调高（最小 72px、最高约窗口 62%），双击恢复默认，高度记在本地。
· 播放监视（左下）有三档监视对象：**跟随音声片段（默认）· 整体混音 · 单独某条轨**。
  默认只显示音声轨当前播放片段的名字和它的电平；选「整体混音」看全轨相加；
  选某条轨就只看那条轨。切换记在本地，下次打开还是这个。
· 素材库（与台本页同一套逻辑：导入台 → 音效库），只有两个页签，统一「两行式」行：
  第一行名字 + 来源小标，第二行时长/采样率/声道；右侧 ▶ 试听 / ＋ 插入播放头 / ⋯ 菜单。
    **🔔 音效库**（默认）  导入台存出来的成品音，拖/双击插入时自动拷一份进本工程；
    **本工程**  工程目录里的音频副本（插入过的都在这），可 ＋加入 / 拖到素材轨 / 重命名 / 删除。
  为什么没有「音色库」：音色是喂给 TTS 模型的参考音频，不能当素材插进时间轴，
  放在素材库里只会让人以为两个库是一回事。
  面板右上「📥 导入台」= **在本页直接打开**导入台（不跳转、不新开标签），
  存完自动回到时间轴并刷新音效库；导入台右上还有「↗ 单独打开」可以开成独立标签页。
  **右键任意一条**都能看「ℹ 属性」（容器/位深/采样率/声道/时长/码率/大小/来源），
  本工程的还能「拷进导入台改一改」。

音轨
--------
· 音声只能放音声轨，素材只能放素材轨；各自有「新建音声轨 / 新建素材轨」按钮（在对应轨道组下方）。
· 音轨可上下调整顺序、双击重命名、M 静音、S 独奏（单独听这条轨）、调音量、删除。
· 素材轨保持在音声轨下方，两组之间隔开。
· 同一轨里两段音频重叠时，保持 0.5 秒后会自动把拖过来的那段放到下方新建的同类型轨，
  避免叠放导致导出错位。

重叠整理 / 导出前提醒
--------
· 传输条「⇄ 整理重叠 (N)」：括号里是当前**同一条轨上时间相交**的片段对数。
  点一下会把冲突的片段挪到同类型的空白轨 / 邻近轨；**位置、时长、源内起点一个都不动**，
  没有空位时才新建一条同类轨。整理完按钮回到「⇄ 整理重叠」。
· 「导出工程」前会先检查重叠：
    · 没有重叠 → 直接进「导出工程包」设置；
    · 有重叠 → 先弹提醒（列出现哪条轨、叠了多少秒），三个选择：
      「取消」/「仍然导出」/「先整理重叠再导出」（整理完自动打开导出设置）。
  为什么要提醒：EDL（PR / 达芬奇）**一条轨就是一个声道**，同一时间放两段会被截断或只剩一段；
  Reaper 的 .rpp 虽然允许叠，但同一轨两段会同时出声、位置也难看准。
  混音导出不受影响（重叠本来就会相加），所以只在「导出工程」时拦一下。
· 波形按「窗口」绘制：峰值数组覆盖整个源文件，裁剪后只画 [源内起点, 源内起点+时长] 那一段，
  所以拖动左右手柄时波形不会再被横向拉伸变形（时间尺度始终一致）。

撤销 / 重做 / 历史版本
--------
· **撤销**：传输条 ↶ 或 Ctrl+Z；**重做**：↷ 或 Ctrl+Shift+Z / Ctrl+Y。
  位移、裁剪、属性、静音、锁定、变速、插入、删除、拆分、整理重叠都能撤。
· 力度是「一次操作一步」：滑杆一路拖、片段一路拖，松手后只算一步（改动停下 0.6 秒才入栈），
  不会因为拖了 50 个像素就吃掉 50 步。上限 80 步，重做栈在产生新改动时自动清空。
· **历史版本**（落盘，换会话 / 关浏览器都还在）：传输条「🕘 历史」。
  · 每次保存后会节流自动存一份（至少间隔 90 秒），最多保留 40 份，超出自动丢最旧的；
  · 也能「＋ 现在存一份」手动打个标记；
  · 每条显示时间、备注、几条轨 / 几个素材，可「回退」或删除；
  · 回退前会先把**当前状态**存一份（备注「恢复前」），回退错了还能再回来。
  · 存储位置：台本目录下 timeline_history/，**与台本页的 history/ 分开**，两边互不影响。

标签挂的音效落在哪条轨
--------
· 位置永远是「标签时间 + 留白」（要挪就改留白），但**落在哪条素材轨是会记住的**。
· 自动避让：生成时优先放到「该时间段空着」的素材轨，都占满了才落在第一条，
  所以两个标签音效不会再叠在同一条轨上。
· 你把标签音效整理到别的轨（手动「⇄ 整理重叠」或拖动）之后，换轨结果会写进工程
  （project.tagfx），刷新、关掉再开都在原位——这就是以前「删掉一个素材，别的片段自己
  挪了位置还叠在一起」的根因，已修。
· 标签音效片段是**派生**的：不能单独删除/拆分（要改请回台本页取消挂载），
  但可以静音、调音量。

操作
--------
拖动片段      改位置（只动这一段，不联动后面的片段）
拖左右边缘    裁掉前后多余的音频（不破坏源文件）
双击片段      从这句开始播
点标尺        定位；拖动标尺    连续拖动播放头
Ctrl+滚轮     以鼠标为锚点缩放；普通滚轮   横向滚动
空格          播放/暂停　Home 回零　←→ 前后 1 秒（Shift 5 秒）
Delete        删除选中的素材片段
右侧属性      位置、时长、源内起点（素材）、音量、声像、速度、淡入、淡出、
              试听 / 恢复默认 / 静音 / 锁定 / 删除（素材）/ 回到台本位置（语音）
· 素材拖到音轨 = 一个完整片段，和语音片段一样可：静音 / 复制 / 剪切 / 拆分 /
  变速 / 调音量 / 调左右声像 / 淡入淡出（音轨和单句都能设）。
· 吸附开关：拖动片段或素材时，会自动吸到标记点和其它片段边缘（可在传输条关掉）。
· 循环开关：播到结尾自动回到开头重播。

素材
--------
右侧「素材库 → 本工程」上传 wav/mp3/flac/ogg（统一转 44.1kHz WAV、**保留原声道**，
复制到工程 media 目录）。上传后：▶ 试听、双击插入到播放头、＋ 插入、拖到音轨、右键属性/重命名/删除。
想批量导入音频/视频、去伴奏、变速变调，请走「📥 导入台」——存成音效后这里「🔔 音效库」就能看到。
拖进音轨的素材 = 一个完整片段，支持和语音一样的全套编辑（静音/复制/剪切/拆分/变速/音量/声像/淡入淡出）。
素材存在 longform/scripts/<id>/media/，随台本走。

导出
--------
「导出混音」弹窗里可选：
  格式      WAV(16/24/32bit 浮点) · FLAC(16/24bit) · MP3 · OGG
  采样率    16k / 22.05k / 32k / 44.1k（默认） / 48k / 96k
            22.05k = 与 TTS 原始输出一致（不重采样、最省）；48k = 视频剪辑标准
            每个选项右边都有「?」，点开是「这个选项做什么 + 对声音有什么影响」的说明
  音质/位深 WAV/FLAC 选位深；MP3/OGG 选质量档（内置编码器，码率上限较低，要高保真选 WAV/FLAC）
  声道      立体声（保留声像）/ 单声道（体积减半）
  导出时段  填「开始/结束」秒只导这一段，留空=整条，右边「整条」一键清空
  包含音轨  勾选要参与混音的轨道（默认勾未静音的）
  弹窗底部实时显示：全片时长、本次导出时长、句数、采样率/声道、**预估文件大小**；
  导出后给出真实大小与码率。
  两小时工程渲染约 1~3 分钟（服务端分块混音，不吃内存）。
「导出工程」第一步先选格式（可多选）+ 工程采样率（写进 rpp 头、决定 stems 分轨采样率），
  每种格式后面都有「说明」按钮，
  点开是分步骤的导入/使用教程（含 Reaper / PR / 达芬奇 / Audacity 的具体菜单路径与注意事项）。
  打包 zip 内含（三种格式可任选，可同时勾）：
  project.rpp      Reaper 直接打开，每句一个 item，位置/音量/淡入淡出都在
  timeline.edl     CMX3600，PR / 达芬奇走「导入 EDL」
  audacity/        Audacity 4 用：每轨一条从 0 秒开始的 WAV + labels.txt（标签轨）+ 导入说明。
                   Audacity 的工程格式 .aup3 是数据库，无法直接生成，所以用业界通行的
                   「分轨 WAV + 标签」方式，导入后时间轴天然对齐。
  stems/           语音、素材各自的整轨混音
  audio/           逐句 wav，按「序号_文本」命名
  timeline.csv     每段起止秒 + 时间码 + 文本
  注：工程导出（rpp/edl）比混音更全 —— 只要片段有音频就导出，「需重生成」的会在名字前标注
      【需重生成】；混音导出仍然跳过这些片段。
  markers.csv      标签标记点，可直接照着铺音效
  README.txt       说明
  「把用到的音频一起打包」勾上 = 自包含（体积大）；不勾 = 引用本机绝对路径（体积小）。

几点要说清楚
--------
· 需重生成的句子不会进混音，时间轴上留空。重生成之后再导一次就填上了。
· 拖动只影响该片段，后面的不会自动顺移（避免你排好的东西被牵动）。
  想恢复："属性"里点「回到台本位置」。
· 工程存在 longform/scripts/<id>/project.json，只记差分；台本重生成不会冲掉你的排布。
· 波形峰值缓存在 peaks/ 里，第一次打开某句稍慢，之后是毫秒级。

工程化与修改撤回
--------
· 工程化：点「保存并进入时间轴」会基于当前台本新建一份「工程副本」（音频用硬链接，
  不复制、不破坏原台本）。原台本即「初始样本」，工程里随时可点「回到初始样本」还原。
· 改了已生成的句子 → 该行变「需重生成（橙）」，行内标出「改了什么」（文本/音色/情感…），
  并出现「↩ 撤回」按钮，一键恢复成生成时的参数与「完成」状态。
· 文本改动会精确标注成「插入 / 删除 / 替换」并给出具体字词（如 文本【插入】“××”），
  不再是笼统的整句对照，避免「明明改了却看起来一样」。
· 时间轴里语音片段默认【锁定】：位置与时间跟随台本时间轴、不可拖动；
  要改先在属性面板或右键「解锁（可改位置时间）」。素材轨片段默认不锁。
· 时间码对照：工程副本改了某句并重生成后，后续句子的时间会跟着平移；属性面板里会显示
  该句「初始样本时间码 X → 当前 Y（偏移 +Ns）」，方便对照进入时间轴那一刻的位置。
· 台本列表分两组：「台本（源文件）」与「工程（时间轴副本）」，工程卡片带「工程」徽标。

音色与预设（顶部按钮）
--------
音色库：多选上传、试听（再点一下暂停）、点名字重命名（磁盘文件名一起改）、删除。
参数预设：把「默认参数」的音色+情感+权重+停顿+采样参数打包存一份，可命名/应用/改名/删除。

撤销 / 历史
--------
↶ 撤销 / ↷ 重做（光标不在输入框时可 Ctrl+Z / Ctrl+Shift+Z）；「历史」里有磁盘副本
（最近 20 份，换会话也在，恢复前会自动再存一份）。

状态是怎么算的
--------
以磁盘为准：audio/<行>.wav 在且文本/参数没变 → 完成；改了文本/音色/情感 → 需重新生成；
文件不在 → 未生成。开跑前会预检音色，缺音色会直接告诉你缺哪几行，不会刷一片红。

数据在哪
--------
longform/refs/      音色库（文件名可读）      longform/presets/   参数预设
longform/scripts/<id>/  script.json（含批量任务）/ audio/ / export/ / history/

实测速度（RTX 5070 Ti Laptop 12G，25 步 / cfg 0.7 / beams 3）
--------
约 1.0~1.3 倍实时：两小时音频 ≈ 2~2.6 小时；两万字 ≈ 340 行（70 字/行）。
num_beams 3 → 1 可到约 1.05 倍实时。

想彻底移除这个扩展
--------
删掉 longform_api.py、web/longform.html、web/longform.js、web/longform.css、
longform/ 目录，以及 server.py 末尾「长篇台本扩展」那段注册代码（工作台已改名，代码里的注释没动）（约 12 行）。


多选复制粘贴（台本页）
--------
工具栏：「复制选中 / 粘贴」两个按钮（就在「批量改属性」旁边）。
· 勾好几句（或 Shift 点一段）→「复制选中」→ 光标点一下要插在谁后面 →「粘贴」；
· 粘贴的内容 = 整行：文本 / 句中标签（含延迟、音效）/ 音色·情感 / 停顿 / 分组 / 备注 / 慢语速；
· **已经生成好的音频也会一起复制**（服务端把 wav 另存一份，两行不共用文件），
  所以粘出来的句子直接能播，不用重跑；
· 快捷键：Ctrl+Alt+C 复制、Ctrl+Alt+V 粘贴（带 Alt 是为了不抢文本框的 Ctrl+C/V）；
· 右键菜单也有（单句/多句两种文案），粘完自动选中新行。

全局默认参数与「撤回属性」
--------
· 改「全局默认参数」任何一项（音色/情感/停顿/分段…）或「应用预设」时，会先弹一个确认框，
  写明「影响多少句、其中几句会变成需重生成」，确认后才生效；取消则控件回读旧值。
  —— 这是为了防止「想加个音色，结果手滑改了默认，整篇都变成要重生成」。
· 工具栏「↩ 撤回属性（N）」：撤回**上一次属性修改**（音色/情感/停顿/标签/默认参数），
  只回退属性，文本、句中标签位置、已生成的音频都不动。鼠标停上去能看到最近几条改动。
· 想连文本一起退，用原来的 ↶（Ctrl+Z）。

ffmpeg（视频抽音频）与 Demucs（去伴奏）
--------
· 导入台底部有一行 ffmpeg 状态：绿点=已就绪（显示版本和路径），黄点=没找到。
  没找到时视频不能抽音频（普通音频导入不受影响），三个按钮：
  「⬆ 上传 ffmpeg.exe」（选本机的 ffmpeg，30~90MB，传进整合包 bin/ 后离线可用）、
  「✎ 填路径…」（直接填绝对路径，也可以填它所在文件夹）、「⟳ 重新探测」。
  设置会记在 longform/config.json，换台电脑只需再传一次。
· Demucs 的 htdemucs 权重（80MB）现在**打包内置**在 vendor2/torch 下，
  第一次用不再联网下载，离线机器也能「只留人声 / 净化人声」。
· 导入台处理完**默认保留原始素材**（勾选框「处理后把原始素材留在导入台」默认勾上），
  方便二次处理；只有取消勾选才会把源文件移进回收站。

时间轴新增操作
--------
· 框选：空白处按住拖一块 → 选中范围内的片段（以前拖一下就断，已修）。
· Ctrl 点选：先点一段，按住 Ctrl 点第二段 → 两段都选中（以前会变成单选，已修）。
· 多段复制粘贴：Ctrl+C 复制选中的多段 → Ctrl+V 在播放头处粘出多段（保持相对时间）。
· 复制属性：Ctrl+Shift+C 复制这一段的所有属性（音量/声像/静音/速度/淡入淡出/空间/混响/关键帧）；
  Ctrl+Shift+V 打开选择窗，勾要贴哪几项。关键帧可选
  「按时间贴（超出目标片长的点丢掉）」或「按时间比例贴（基准可选显示区段 / 整条片长）」。
  批量条上也有「📋 复制属性 / 📌 粘贴属性」，选多段后一次贴完。
· 变速：右键「⚡ 调整速度…」→ 滑杆 + 数字，「变速成固定时长」可以直接填目标秒数自动算速度；
  改完片段在轨道上的宽度会跟着变。属性面板里的速度滑杆同理。
· 淡入淡出：右键「🌗 淡入 / 淡出…」，按**片段显示的那一段**算，淡入+淡出不会超过片段长度；
  裁短或变速后会自动收窄。
· 属性面板的「位置 / 时长 / 源内起点」现在都是「数字框 + 滚动条」，拖着比敲数字快。
· 轨道头右键（以前只有「⋯」）：多了「🌫 整轨混响…」「📌 把复制的属性套到整轨…」
  「⚖ 整轨统一音量…」，一条轨上几十段也能一次改完。
· 标记悬浮窗：顶栏「🪟 标记悬浮窗」可以关掉（关掉后鼠标扫过标记不再弹窗，插入素材走右键菜单）。
  悬浮窗里的「＋ 插入素材」现在是三个库：音效库 / 音色库 / 导入台。
· 自动化脚本从 8 个加到 13 个（贴耳微晃 / 头顶环绕 / 掠耳而过 / 远近呼吸 / 背后低语），
  插入点数量上限从 64 提到 512。
· 波形竖线的疏密现在跟可视区宽度走：短片段和长片段看起来一样密，放大是「线变疏」而不是「线变少」。


时间轴：重排延迟 / 复制语音 / 总时长（本轮新增）
--------
· 顶栏「↕ 重排音声延迟」：按台本里的句间停顿，把音声片段按句子顺序依次排开。
  只改开始时间——时长、裁剪、音量、空间、关键帧都不动，素材轨上的片段完全不受影响。
  操作前有说明弹窗；片段的「锁定」会临时解开写入新位置、写完立刻锁回，锁不会丢。
· 语音片段现在也能复制：选中 → Ctrl+C → Ctrl+V，会把它复制成**一条独立的素材片段**
  （在工程 media 里另存一个 wav）。它跟台本脱钩：改名、裁剪、删除都不影响原句，也不会多出一句。
· 总时长：把片段往右拖出原来的长度，总时长会自己变长；顶栏那个「总时长」也能点一下手动改。
  导出混音的弹窗里多了一项「总时长算到哪儿」：
  按最后一段的**显示末端**（和看到的一致）或**未显示部分末端**（被裁掉/变速压掉的那段也算）。
· 单选只有红框；按住 Ctrl 点第二段才会同时出现紫圈和勾标（多选）。

变速 / 属性面板（本轮修正）
--------
· 右键不再有 ×0.9 / ×1.1；用「⚡ 调整速度…」（滑杆 + 数字 + 变速成固定时长）。
· 属性面板的速度滑杆 0.5–2，**中间就是 1×**（往左变慢、往右变快），下面一行「变速时长」可以直接填目标秒数。
· 位置 / 时长 / 源内起点 的滑杆缩短了，右边的数字框不会再被挤出去。
· 变速之后片段在轨道上的显示长度会跟着变，而且右边缘**不会**再能拉回原来的长度（上限按速度折算）。

界面（本轮）
--------
· 时间轴的标尺和播放头现在始终贴在顶部：纵向滚到再下面也看得见刻度，还能直接拖标尺定位播放头（双击回全览）。
· 波形改成连续填充的包络（不是一根根竖线），长短片段、放大缩小看起来一致。
· 台本页右侧：进度条搬到了「批量 / 生成 / 导出」上方，切页签也一直可见；
  最上面新增一行状态：模型 / ffmpeg / 人声分离（Demucs，带 CPU/GPU 与是否离线权重），右边 ⟳ 可重检。
· 标签面板里「▶ 试听」再点一下会变「⏸ 暂停」。


第一次用？看教程
--------
台本页顶栏最左边有个「🎓 第一次用？看看这里」，点开是一份带截图的六步教程：
导入台本 → 提取音色 → 生成音声 → 加入音效 → 时间轴编辑 → 导出混音，
每步都写了「在哪个位置、按哪几个按钮」，最后还有快捷键小抄和常见问题（ffmpeg / 去伴奏 / 模型加载 / 总时长…）。
教程是**离线**的（图片随包分发，地址 <本机>/guide），不影响正在编辑的台本。

音频片段：变速后的波形（本轮修正）
--------
· 变速改的不只是片段宽度：波形会跟着一起被压缩 / 拉伸（2× 的片段波形被压扁，0.5× 被拉宽），
  以前只有宽度变、波形不变，看着像没生效。
· 波形颜色调淡了：它现在只是背景底衬，不会压过关键帧曲线（音量 / 声像 / 空间）。

音声片段的两条新规则
--------
· 右键里音声片段**没有「剪切」**（只有复制）：剪切会把台本那一句的音频搬走，容易误会。
· 想把某一句当素材反复用：右键 →「⧉ 复制到素材轨『音声副本音轨』」。
  副本会另存成一个独立 wav，落在一条叫「音声副本音轨」的素材轨上
  （位置在所有音声轨下方、其它素材轨上方），随时能用、随便剪，
  台本里不会多一句，删掉也不影响原句。
· 只是 Ctrl+C / Ctrl+V 也可以：粘出来同样是独立素材，会落在当前素材轨。
· **多选也能一次复制**：Ctrl 点 / 框选好几段音声，右键 →「⧉ 复制选中的 N 段到『音声副本音轨』」，
  一次全过去（原来只复制右键点中的那一段）。选中的片段里如果有还没生成音频的，会自动跳过并提示。
· 副本会连同**音量 / 声像 / 空间 / 混响 / 关键帧曲线**一起复制（关键帧以前会丢，导致副本变成一条直的声音）。
· 多选后右键「静音」也是作用于整批，不再只静音点中的那一段。

重排音声延迟：现在跨音轨按句序
--------
以前是「每条音声轨各自从头排」，句子一旦分散在多条轨上，排完顺序会乱。
现在无论句子在哪些音声轨上，都按台本句序排成一条时间线：
第 1 句接第 2 句 + 停顿，再第 3 句……轨道上有没有空白都不影响。
片段仍然留在各自原来的轨上（不会为了排序而换轨），素材片段完全不动。

多选整组拖动
--------
选中多段（Ctrl 点 / 框选），按住其中任意一段拖：
所有选中的片段一起移动，相对位置保持不变；上下拖到别的轨也是整组一起换。
（如果只是点一下不拖，仍然会收成「只选这一段」。）

内置 ffmpeg
--------
补丁包现在自带 ffmpeg（bin\ffmpeg.exe），装完就能直接拖视频进导入台抽音频，
不需要你另外装，也不需要联网。导入台底部那行状态会显示为绿点「ffmpeg 已就绪」。


我的台本：多选（本轮新增）
--------
左侧台本列表现在支持多选：
· 普通单击 = 打开这一份（和以前一样，会清掉多选）；
· 按住 Ctrl 点 = 逐个加选 / 再点一次取消；
· 按住 Shift 点 = 从上次点的那一份连选到这一份（锚点不动，可以反复调范围）；
· 选中后列表上方出现一条蓝色批量条：「已选 N 份 / 全选 / 复制 / 删除 / ✕」；
· Esc 取消选择。
批量删除会列出前几份的名字让你确认；批量复制会给每份各建一个副本（含已生成音频）。
右键菜单在多选状态下也会变成「删除这 N 份 / 新建副本（N 份）」。

轨道顺序：音声组 / 素材组分开排（本轮修正）
--------
· 轨道头右键现在有「移到音声轨组第一条 / 最后一条」「组内上移一格 / 下移一格」。
  这些操作都只在自己那一组里挪，音声轨和素材轨永远不会互相穿插。
· 新建音声轨会加在音声组末尾、新建素材轨加在素材组末尾。
· 「⧉ 复制到素材轨『音声副本音轨』」固定插在**素材组的第一条**
  （也就是所有音声轨下方、其它素材轨上方），不会再跑到最下面。
· 顺手修了一个隐患：老工程里轨道数组可能是交错的（界面看着分组、数组是乱的），
  于是「插在某条轨后面」算出来的位置和眼睛看到的对不上。现在读写工程都会把数组理顺成
  音声组 + 素材组，顺序和界面一致。

导出的两个小修正
--------
· 工程里一个能出声的片段都没有时，「导出工程」不再生成一个空包，而是直接提示
  「没有可导出的片段」。
· 有片段的音频文件不见了（比如素材被删），导出会跳过它并在完成提示下面写
  「⚠ 有 N 段的音频文件不见了，已跳过」，不会假装成功。
· 下载链接统一做了 URL 编码：文件名里有中文、空格、「·」也能正常点开。

教程里的「全功能地图」
--------
「🎓 第一次用？看看这里」除了六步流程，下面还有一张「全功能地图」。
它按「一篇文章 → 一条成品」的顺序分成五个阶段，遇到不会用的功能按阶段翻就行：

  阶段 1 · 备料：智能导入、素材导入台、三个素材库的分工
  阶段 2 · 台本：我的台本（源文件 / 工程 / 多选）、智能分行、分组、筛选与状态
  阶段 3 · 生成：批量生成与单句重做、句中标签 / 句间标签
  阶段 4 · 时间轴：常用操作、片段属性、轨道属性、关键帧/录制/空间音频/运动脚本
  阶段 5 · 导出与维护：导出方案（混音 / 工程包 / 单句 / 拼接）、清理空间

其中「智能导入」写清了四种分行方案和五类稿子的识别规则：

  · 四种分行方案
    - 按长度（默认）：先按 。！？!?… 和换行切成小句，再合并到「单段上限」（默认 70 字）；
      引号括号内部不切，单句本身超上限才在逗号处软切。最通用。
    - 一句一行：一个句末标点一行，不再合并。适合逐句精修、要逐句挂标签。
    - 一段一行（按空行）：按空行分段，每段一行。适合已排好版的口播稿。
    - 一行一段（不切也不合）：原文一行就是一行，不切句也不合并。
      用来把「⤓ 导入原稿」下载的文件原样重来，分段和当初完全一致。
  · 五类识别
    - ⏱ 时间轴类（有时间码 / SRT）：按时间码切并保留原时间轴
    - 🎭 剧本类（角色：台词 / 引号）：按角色切，角色名进分组不进正文
    - 📖 小说类（第 x 章 / # 标题）：按段落切、按章节分组
    - 🏷 指令类（【镜头】/ [pause=500]）：标记转停顿/分组，不朗读
    - 🧩 纯文本：以上都没有，用四种分行方案里的某一种
  · 切完之后还能调：单段上限、分组方式（不分组/章节/角色/场景/每 N 段一组）、
    每段后停顿、预设（口播稿、逐句精修、按段落、长文分批…），预览里每一段都能拆分/合并/改。
  · 导入后想重切：工具条「智能分行」，两种模式 + 字数上限 + 处理范围（只未生成 / 全篇）。

配图 25 张都是实拍（六步流程 6 张 + 全功能地图 19 张），点一下能放大。

多选时的一致性（本轮修）
--------
· 锁定：多选几段后按 L（或右键「锁定选中的 N 段」）→ 整组一起锁；
  如果几段状态不一样，**优先全部锁定**，再按一次就全部解锁。
· 拖动：多选后拖任意一段，整组一起走；上下拖到别的轨时，同类型片段会**全部落到同一条轨**
  （以前是各自按轨序平移，本来分散的拖完还是分散的）。
  注意：音声片段默认是锁定的，整组拖动会先把它们的锁解开（不然服务端不认位置改动），
  想锁回去按 L。
· 右键的「删除 / 淡入淡出 / 变速」在多选下都作用于整批，菜单上会写「选中的 N 段」。
· 静音、复制属性、复制到素材轨同理，都是整批。

重度使用 / 并发相关的几条（本轮修）
--------
· 快速连点几份台本：最终打开的一定是**最后点的**那份（以前偶尔会回退到先点的那份）。
· 渲染中切台本：进度、状态只属于发起的那个台本，不会串到新开的台本上；
  同一时间只能跑一个渲染任务，第二个会提示「已有一个台本在渲染」。
· 时间轴连着拖两下 / 批量改完再改一段：保存按顺序排队（PATCH 不乱序），界面不会再退回上一版。
· 改完立刻关页面 / 刷新：会先抢存一次再弹确认，不会静默丢改动；保险起见，看到右上角显示
  「已保存 时:分」再关最稳。
· **别在两个标签页里同时编辑同一份台本 / 同一个工程**：保存是「后写的赢」，两边会互相覆盖。
· 撤销栈有条数上限（台本 80 步、时间轴 80 步），长时间编辑不会把内存吃爆，但很早以前的步骤会逐步淘汰。
