# 移植到其它整合包 / 其它 TTS

本工作台不是独立服务，它是**挂在某个 FastAPI 主程序上的扩展**。整体思路只有一句话：

> 把几个模块放进去 → 在 `server.py` 里注册两条路由 → 准备数据目录 → 给一个「能生成 wav」的 TTS 适配器。

下面按顺序讲。照着做，一个下午能接上；只想要现成可用的，直接用补丁包（见 README）。

---

## 0. 先确认目标包够不够「像」

目标整合包需要满足（缺一项就要先补）：

| 条件 | 为什么 | 不满足怎么办 |
|---|---|---|
| 有一个 FastAPI 的 `app` | 扩展要往上挂页面路由（`/longform`、`/timeline`、`/guide`） | 其它框架要自己加等价路由 |
| 有一个 `api = APIRouter(prefix="/api/v1")`（或同级的 router） | 扩展的业务接口挂在它下面 | 换前缀也行，但前端 `API` 常量要跟着改 |
| 有 `web/` 静态目录，且主程序能返回里面的文件 | 前端是纯静态（html/css/js） | 自己加静态挂载 |
| 有 Python 环境（最好是**自带 `runtime\python.exe` 的便携包**） | 安装器靠它跑 | 系统 Python 也行，改 `安装.bat` 里的探测 |
| 有一个能「文本 + 参考音频 → wav」的推理入口 | 工作台只管编排，不管合成 | 写适配器（见第 4 节） |
| 端口和路径可控 | 页面里用相对路径，不写死域名 | 一般都没问题 |

> 本仓库的安装器是按 **IndexTTS2 v3 便携整合包** 的 `server.py` 结构写的（`app` / `api` / `current_dir` / `tts` / `_INFER_LOCK` / `logger` / `cmd_args`）。
> 结构不一样不是不能装，而是**注册块要手工改**，安装器只是帮你省掉复制文件这一步。

---

## 1. 文件清单：放什么、放哪儿

全部放在**目标整合包的根目录**（和 `server.py` 同级）：

```
<整合包根>/
├─ longform_api.py          ← 必需：台本工作台后端
├─ lf_import.py             ← 必需：智能导入（五类识别 + 分行规则）
├─ timeline_api.py          ← 必需：时间轴后端（依赖 longform_api 的工具函数）
├─ hrir.py                  ← 必需：HRIR 读取（没有 HRIR 数据时自动回退球头模型）
├─ rooms.py                 ← 必需：房间混响
├─ web/
│   ├─ longform.html/.css/.js
│   ├─ timeline.html/.css/.js
│   ├─ emoctl.js            ← 两个页面共用的情感控件
│   ├─ guide.html
│   └─ guide/*.png          ← 教程配图（可选，删了教程页会缺图）
├─ assets/hrir/             ← 可选：HRIR 数据（.sofa / .npz），见该目录 README
├─ bin/ffmpeg.exe           ← 可选：视频抽音频、mp3/flac 编码
├─ vendor2/torch/...        ← 可选：Demucs 离线权重
└─ _vendor/h5py/...         ← 可选：读 .sofa 需要（或直接 pip install h5py）
```

数据目录不用手工建：第一次调用时会自动创建

```
longform/
├─ scripts/<sid>/          台本 JSON + audio/（逐句 wav）+ media/（工程素材）
├─ refs/                   音色库（参考音频）
├─ sfx/                    音效库
├─ materials/              导入台原始素材
├─ presets/                参数预设
├─ _import/                导入中转
├─ _trash/                 回收站
└─ config.json             全局配置（ffmpeg 路径等）
outputs/                   导出产物（混音、工程包）
```

## 2. 接线：`server.py` 里加一段注册

在 `server.py` **已经创建好 `app` 和 `api` 之后**、`if __name__ == "__main__":` 之前插入：

```python
# ---- 全能音声工作台（longform + timeline）----
try:
    from longform_api import register_longform
    register_longform(app, api, deps={
        "tts": tts,                          # 你的 TTS 适配器（见第 4 节）
        "infer_lock": _INFER_LOCK,           # 推理锁，串行化生成
        "logger": logger,
        "project_dir": current_dir,          # 整合包根目录
        "web_dir": os.path.join(current_dir, "web"),
        "verbose": cmd_args.verbose,
    })
except Exception as e:
    logger.error("longform failed: %s", e, exc_info=True)

try:
    from timeline_api import register_timeline
    register_timeline(app, deps={
        "project_dir": current_dir,
        "web_dir": os.path.join(current_dir, "web"),
        "verbose": cmd_args.verbose,
    })
except Exception as e:
    logger.error("timeline failed: %s", e, exc_info=True)
```

要点：

- **两段都要 `try/except`**：扩展挂了不能拖垮主界面（这是设计原则）。
- **顺序不能反**：`timeline_api` 会 `from longform_api import ...` 复用工具函数，必须后注册。
- 名字对不上（没有 `current_dir` / `logger` / `cmd_args`）就换成目标包里等价的变量；
  安装器的 `_server_block()` 就是干这个的，可以照着它的兜底写法改。
- 注册函数内部会自己 `app.include_router(...)`，**不要**再在别处重复 include。

然后加首页入口（可选，但推荐）：在 `web/index.html` 的导航里加一行

```html
<a href="/longform">长篇台本</a>
```

> 安装器只在找不到 `<nav class="tabs"` 时才会失败并提示手工添加。其它模板随便放哪儿都行。

## 3. 依赖

**必需**（整合包里通常都有）：

```bash
pip install fastapi numpy soundfile
```

**可选**（缺了会自动降级，不会崩）：

| 包 | 用途 | 缺了会怎样 |
|---|---|---|
| `scipy` | 高质量重采样（`resample_poly`）、滤波 | 退化到线性插值重采样，高频略糙 |
| `h5py` | 读 `.sofa` 格式的 HRIR | 只能用 `.npz` 或球头模型 |
| `torch` + `demucs` | 「去伴奏 / 只留人声」 | 导入台里该选项不可用，只剩 DSP 中置提取 |

> 便携包里装包：`runtime\python.exe -m pip install scipy h5py`。
> 离线机器可以直接把 `site-packages` 里的目录拷进 `_vendor/`，`hrir.py` / `timeline_api.py` 会尝试从那里导入。

## 4. 接自己的 TTS：写一个 40 行的适配器

工作台**只依赖 `deps["tts"]` 的三个方法**，不关心你用什么模型：

```python
class MyTTSAdapter:
    """把任意 TTS 包成工作台认的形状。"""

    def __init__(self, ...):
        self.model = None

    # ① 给前端「模型状态」用（顶栏那条状态灯）
    def state(self):
        return {
            "loaded": self.model is not None,
            "phase": "ready" if self.model is not None else "idle",   # idle/loading/ready/error
            "device": "cuda",             # 可选，展示用
            "model": "my-tts-v1",         # 可选，展示用
            "reason": "",                 # phase=error 时给原因
        }

    # ② 真正加载模型（懒加载，第一次生成时调用）
    def ensure_loaded(self):
        if self.model is None:
            self.model = MyModel(...)
        return self.model

    # ③ 情感向量归一化（没有情感功能就原样返回）
    def normalize_emo_vec(self, values, apply_bias=True):
        return values
```

返回的 `model` 必须有一个 `infer(...)`，把音频写到 `output_path`：

```python
def infer(self, *, spk_audio_prompt, text, output_path,
          emo_audio_prompt=None, emo_alpha=0.65, emo_vector=None,
          use_emo_text=False, emo_text=None, use_random=False, verbose=False,
          max_text_tokens_per_segment=120,
          do_sample=True, top_p=0.8, top_k=30, temperature=0.8,
          length_penalty=1.0, num_beams=1, repetition_penalty=2.0,
          max_mel_tokens=1000, interval_silence=200):
    wav = my_model.synthesize(text, ref=spk_audio_prompt, **{...})
    sf.write(output_path, wav, sr)        # 必须是 wav，路径由工作台给
    return output_path
```

工作台还会读几个**可选属性**（有就用，没有就跳过）：

| 属性 | 用途 |
|---|---|
| `model.gr_progress = fn(value, desc)` | 段内进度回调（`0~1`），没有就不显示细进度 |
| `model.mel_tokens_capped` | 是否因为 token 上限被截断，用于给句子打「可能没读完」的提示 |
| `model.text_normalize_fallback` | 文本正则/归一化失败时的提示 |

**只支持「整句合成」也能用**：把 `max_text_tokens_per_segment` 之类参数忽略即可。
如果模型一次只能读很短的句子，就把工作台的「单段上限」调小（台本页能设，默认 70 字）。

## 5. 前端要改的地方（只有一处）

`web/longform.js` 与 `web/timeline.js` 开头有：

```js
const API = "/api/v1/lf";        // longform.js
const API = "/api/v1/lf/tl";     // timeline.js
```

如果目标包的路由前缀不是 `/api/v1`，改这两行即可。页面本身全部用相对路径，不写域名和端口。

静态文件的返回路由已经在模块里注册好了（避免主程序静态目录配置不同）：

- `/longform`、`/longform-assets/{name}`（白名单：`longform.js/css`、`emoctl.js`）
- `/timeline`、`/timeline-assets/{name}`（白名单：`timeline.*`、`emoctl.js`）
- `/guide`、`/guide-img/{name}`（教程页与配图）

## 6. 平台差异（Windows 之外）

| 项 | Windows 便携包 | Linux / macOS |
|---|---|---|
| 安装器 | `安装.bat` + `install.py`（纯 ASCII，防 GBK 乱码） | 直接 `python install.py`（`.bat` 无效） |
| Python | `runtime\python.exe`（3.11） | 系统 python3.10+ |
| ffmpeg | 放 `bin\ffmpeg.exe` | 放 `bin/ffmpeg` 或用 `apt/brew install ffmpeg`；也可设环境变量 `LF_FFMPEG` |
| 路径分隔 | 反斜杠 | 代码里都用 `os.path.join`，无硬编码 |
| 文件锁 | Windows 删文件偶尔会被占用（导出时用「改名暂存」兜底） | 基本不会 |
| 显存 | 整合包自带 CUDA 运行时 | 需要自己装对应 torch |

## 7. 常见的坑（按踩到的概率排序）

1. **控制台编码**：中文 Windows 的 `cmd` 是 GBK（936）。`.bat` 里只要有一个非 ASCII 字节，
   就会被拆成 `'t' 不是内部或外部命令` 这种乱码。规则：**`.bat` 全 ASCII + CRLF，中文交给 Python 打印**。
2. **路径里有空格 / 中文**：所有 `subprocess` 调用都要加引号；写文件用 `os.path.join`，不要拼字符串。
3. **路由前缀冲突**：扩展用的是 `/api/v1/lf/*` 与 `/api/v1/lf/tl/*`。如果目标包已经占了 `lf`，换前缀并同步改两个 `const API`。
4. **静态资源缓存**：前端资源一律 `Cache-Control: no-store`，否则改完页面刷新没反应（这是血泪教训）。
5. **注册块插错位置**：必须插在 `app` / `api` 创建之后、`include_router` 之前；插到 `__main__` 之后不会生效。
6. **模型接口不一致**：不同版本的 IndexTTS2 `infer()` 参数名可能变（比如新增/改名）。报 `TypeError: unexpected keyword` 时，
   按第 4 节把多出来的参数吃掉（`**kwargs`），或改 `_render_one()` 里的调用。
7. **`locked` 片段**：音声片段默认锁定位置，任何批量改位置的操作（重排等）都要先临时解锁、写完再锁回，
   否则服务端会拒绝 `start` 变更，表现是「点了没反应」。
8. **大文件**：`ffmpeg.exe`（~85MB）和 Demucs 权重（~80MB）不要进 git；用 Release 附件或首次运行下载。
9. **HRIR 授权**：KEMAR 无使用限制（需引用），KU100 近场是 CC BY-SA；商用前确认，别把这事留给用户。
10. **删除型测试**：服务里如果有「批量删除/清理」的守卫（某些沙箱会加），跑测试时可能把服务一起带走；
    开发时把「跑删除型测试」和「给用户留一个能用的服务」分成两个进程。
