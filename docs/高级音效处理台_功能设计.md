# 高级音效处理台 · 功能设计

> 2026-11-03 ｜ 页面 `/sfxbench`，入口在素材导入台底部（与「模型拓展」并排，左侧那颗）
> 定位：**把一段音声拆成可复用的音效片段**。只做"分离 + 切段 + 挑拣 + 入库"，
> 不做"保留喘息 / 音效语义识别"（已论证不可行，见《气声与非语音人声分离_评估.md》）。
> 形态：**三条轨**（原音 / 处理后 / 字幕）+ 导航窗 + 片段列表；编辑全在波形上直接做。

---

## 1. 边界

**做**：从原音里把**非人声部分**（环境、道具、衣物、脚步、雨声……）切出来，带着原始时间戳入库，
供汉化后的时间轴重新使用。

**不做**：

| 不做 | 原因 |
| --- | --- |
| 保留喘息/舔耳/口腔音 | 它们和台词同属"人声"，BS 判 100% 人声，没有可用的分离依据（实测见评估文档 §8） |
| 三轨（Vocal 单独留一层） | 同上；留着只会让用户以为"能从人声轨里挑音效" |
| 音效语义分类/自动命名 | CLAP 在中英混合的近场素材上置信度低，命名交给人或 SRT |
| 全程一键 | 切段是"挑"的活，机器铺 80%、人挑 20% 才是正确分工 |

---

## 2. 适用场景

| 场景 | 用法 |
| --- | --- |
| ASMR 汉化 | 原音声去掉台词，取出雨声/衣物/道具音，中文配音后垫回去 |
| 有声书 | 从参考音轨取环境音、翻页声、脚步，做成该书的音效库 |
| 影视/广播剧二创 | 从成片里取音效做素材库（注意授权） |
| 素材整理 | 把一坨长录音切成短片段，批量入库 |

## 3. 功能清单

### 3.1 素材与分离（已有）

- 从导入台选素材，带搜索与时长显示；
- 四种处理：BS-Roformer / Demucs / 中置提取 / 不分离；
- 精度（Demucs）与残留抑制（0–15%）；
- **分离只做一次**：结果落盘成作业文件，改切分参数不重跑；
- 作业目录按 mtime 保留最近 N 个（见 §3.6）。

**新增：分离有效性提示**。分离后算 `伴奏 / 原音` 的电平比：

| 比值 | 提示 |
| --- | --- |
| < −20 dB | ⚠「这条素材几乎全是人声，分离后基本是空的」+ 建议改用「不分离」直接从原音切 |
| −20 ~ −8 dB | 「分离结果偏少，可能大部分内容都在人声轨」 |
| ≥ −8 dB | 正常 |

四段真实测试素材（喘息×2 / 舔耳 / 运动）全部落在第一档（伴奏 −20~−40 dB），
这个提示能直接省掉一次白跑。

### 3.2 切分（已有 + 新增一种）

| 模式 | 依据 | 适用 |
| --- | --- | --- |
| 按静音间隔 | 逐帧 RMS + 门限 + 合并小缝 | 通用，最稳 |
| 先减稳态背景 | 中位谱减后再按间隔 | 连续雨声/风扇下的短事件 |
| 按起始点 | 谱通量 onset | 节奏/打击类 |
| **按字幕间隔（新）** | SRT 给的"说话区间"取补集 | **有字幕时最准**：字幕之外就是音效 |

参数：最小间隔 / 最短片段 / 门限 / 前后留白。后三种之外，字幕模式只用「最小间隔」
（两条字幕之间的缝小于它就并成一段）。

**为什么字幕模式比 RMS 准**：RMS 只能判断"有没有声音"，而台词和音效都有声音；
SRT 直接告诉你"哪一段在说话"，补集就是干净的音效候选区。这也是本页要接 SRT 的真正理由。

### 3.3 SRT 参考层（本轮新增）

用途：**在原音时间轴上标出"哪里在说话、多长"**，作为人工切段的参照。
与工作台的台本/时间轴逻辑**完全无关**，只是画在波形上的参考色带。

- 载入方式：拖入 / 选择 `.srt` 文件，或直接粘贴文本；
- 编码：优先 UTF-8，失败自动退 GBK（中文 SRT 常见 GBK，直接按 UTF-8 读会全是乱码）；
- 解析宽容：序号行可有可无、`,` / `.` 都认、忽略位置标记与样式标签；
- 显示：波形上方一条 16px 的字幕带（**青色**，与切分片的紫色区分），悬停显示该条文本与起止；
- 悬停整条波形时，右下角显示"当前时刻属于第几条字幕 / 不在任何字幕内"；
- 可开关显示；「跳到下一条字幕」按钮（对齐切点时用得上）；
- 状态行：`23 条字幕 · 覆盖 3:12 / 5:40`。

| 功能 | 状态 |

| **每张卡一个 ?** | 已做：逐条解释选项作用与默认值的理由 |

### 3.4b 三条轨：为什么要有原音轨和字幕轨

| 轨 | 数据来源 | 能不能编辑 | 作用 |
| --- | --- | --- | --- |
| **原音** | 素材文件本身（`GET /lf/sfxb/raw/{job}` 直接流原文件，不复制） | 只读 | A/B 对照：这段在原始作品里到底是什么声音 |
| **处理后** | 作业文件 `longform/sfxb/<job>/source.wav` | 可编辑 | 切段、改边界、合并、入库 |
| **字幕** | 用户载入的 SRT（只在前端） | 只读 | 每句一块，点一下就跳到那句；悬停看全文 |

**为什么原音不复制一份进作业目录**：6 分钟立体声 float32 就是 700MB 级，为了对照再存一份不值。
素材文件本身只读，直接流出去最省事；`prepare` 顺带把原音的包络（1400 个峰值点）一起返回，
所以两条轨能同时画出来，不用第二次请求。

**两条音轨怎么做到"独立静音"又不错位**：两个 `<audio>`（`auRaw` / `auProc`）共用一个播放头，
播放/暂停/跳转都同时施加到两个元素；`timeupdate` 里做漂移纠正（差 >150ms 才拉回）。
每轨有自己的 `muted` 与 `volume`，还有一颗「▶ 只放这条」——按下时把另一条临时静音，
用来回答"原音里这一段是什么"。分离不改长度，所以两轨天然对齐。

**字幕轨为什么要做成"一块一块的"**：原来只在波形顶上画一条细带，密集时根本看不出边界。
现在每句是一个块，两端画竖线（= 起止），块够宽就写条号；点块 = 跳到那句并播放；
悬停用 HTML 浮层显示**完整台词**（canvas 的 `title` 在长文本上不可控）。

### 3.5 输出（已有 + 新增）

- 存入**音效库**或**导入台**，带上来源素材名与处理链（`音效台 · BS-Roformer`）；
- **导出清单**（CSV / JSON）：名字、起止、时长、来源、引擎 —— 用于外部剪辑软件或二次处理；
- **批量插入时间轴**（已做）：见 §3.7。

### 3.7 批量插入时间轴：四档换算

原片 12.4 秒的关门声，中文配完只剩 4 分钟时该落在哪儿？靠**台本行的原始时间 `t0`**
与**片段当前 `start`** 组成的锚点表做分段线性映射。

| policy | 换算 | 适合 |
| --- | --- | --- |
| `follow`（默认） | 按所在句的局部斜率（句子压得越狠，里面的音效也压得越狠） | 与台词同步：翻页、杯子放下、脚步 |
| `abs` | 按全片新总长 / 原总长 | 环境音、背景（位置本来不精确） |
| `snap` | follow 之后吸附到 ±0.4s 内最近的句边界 | 多数"说完才响"的音效 |
| `seq` | 不换算，依次接在最后一条素材之后 | 台本没有原始时间码时的兜底 |

**三个设计决定，都是踩过才定下来的：**

1. **锚点只用行首 `t0 → start`，不用行尾**。没生成中文时行的 `dur` 是按字数估的
   （5 个字 ≈ 1 秒），拿它当锚点会把一句 6 秒的日文映射成 1 秒 —— 实测压缩比 0.167，
   音效全挤在开头。行首是打轴给的实数，可靠；
2. **新总长只算语音轨**。`abs` 的系数用"所有片段最右端"算，插一次素材总长就变长，
   系数跟着漂（实测第二次插入从 0.67 漂到 2.33）；
3. **返回每段的压缩比**，<0.7 或 >1.3 标黄提示 —— 句子被压得太狠时，音效位置本来就没什么意义，
   这活儿得交给人判断，不该悄悄照算。

片段带 `orig: {t0, t1, policy}` 落库，将来台本再重排时可以据此重算位置。

### 3.8 局部波形缩放（已做）

`−` / `+` / `全` 三个按钮，外加**滚轮缩放**（以指针为中心）与**拖动平移**；双击回到全长。
放大后字幕带、分段底色、包络、播放头都按可视窗口重算 —— 切点差 20ms 时靠数字框猜太慢，
能拉近看才改得准。

### 3.9 相似片段查重（已做）

同一段音效在原片里出现 20 次是常事，只需要入库一次。

- **不比波形**：每次出现都带不同底噪、相位、电平，逐样本对齐基本匹配不上；
- 改用**对数梅尔谱沿时间取平均 + 去均值归一化**（32 带，60–8000 Hz），比频谱形状；
  余弦 ≥ 0.985 且时长比在 0.6–1.7 之间才归为一组（并查集合并）；
- 界面上重复行压暗、标「重复」，检测完出现「删掉重复」按钮，每组的第一个保留。

### 3.6 作业与磁盘

- 作业目录 `longform/sfxb/<job>/`：`source.wav` + `meta.json`；
- 保留最近 **8** 个，按目录 mtime 清理；
- **启动时扫一遍**（不依赖内存字典）—— 现在只按内存记账，重启即失忆，
  磁盘上已经积了 16 个目录 / 361 MB，「只留 8 个」从来没生效过；
- 过期作业访问返回 404 + 明确文案。

## 4. 接口

| 接口 | 说明 |
| --- | --- |
| `POST /lf/sfxb/prepare` | 去人声 → 落盘作业 → 返回 `<job, env, sr, dur, engine, sep_db>`（`sep_db` 新增） |
| `POST /lf/sfxb/segment` | 切分；`mode ∈ {gap, fg, onset, srt}`；`srt` 模式带 `cues: [[t0,t1],...]` |
| `GET /lf/sfxb/audio/{job}` | 整条试听（Range） |
| `POST /lf/sfxb/save` | 勾选片段入库（sfx / media） |
| `POST /lf/sfxb/export` | 导出清单（CSV/JSON），由前端生成，无需服务端 |

数据：

```json
// 片段
{ "i": 0, "start": 12.34, "end": 15.02, "dur": 2.68, "peak": 0.42, "rms_db": -23.1 }
// 字幕
{ "i": 1, "t0": 12.0, "t1": 14.2, "text": "……" }
```

## 5. 交付形态：补丁分层

这个页面和 BS 模型**都不属于基础安装**，分三层交付：

| 层 | 内容 | 体积 |
| --- | --- | --- |
| 基础包（已有） | 工作台、时间轴、导入台 | — |
| **增量补丁 A：高级音效处理台** | `sfxbench.*`、`/lf/sfxb/*`、静态白名单、教程页 | 几十 KB |
| **增量补丁 B：BS-Roformer 模型（可选）** | `vendor2/roformer/` 权重（275 MB/个） | 275 MB+ |

- A 不打补丁也能用 Demucs / 中置提取，只是分离质量差一档；
- B 单独发，用 `pmscli download` 或手动放目录；打包脚本默认**不包含**权重
  （`tools/make_patch.py` 的 `skip_files` 已排除），需要显式 `--with-roformer` 才带上；
- 页面上「引擎」下拉在没有 B 时自动把 BS-Roformer 标灰，并给下载命令。

## 7. 已知限制

1. **切出来的是混合体**：同一时刻的摩擦+心跳+底噪会一起切进一段；
2. **字幕模式的假设**：字幕覆盖"所有说话"。若原片说话没做完字幕，那段会被当成音效；
3. **BGM 会跟着走**：原片有背景音乐时，音乐也会被切进片段（这是素材本身的性质，不是 bug）；
4. **双耳信息保留**：全程 stereo，不做单声道化（相位差就是方位感）；
5. 单个素材上限 512 MB（44.1k 立体声约 50 分钟），更长的需先裁；
6. **允许重叠片段**：手动「标记」和跨段合并都会产生重叠，列表按起点排序显示；
   重叠段入库会各自导出，不会自动裁掉交叠部分 —— 这是有意的（同一段声音可能要截两个不同长度）。
