# 全能音声工作台（台本 + 时间轴）· 补丁包

这是一份**纯增量补丁**：把它装进任意一个 **同款 IndexTTS2 v3 整合包**（Windows 便携版，
自带 `runtime\python.exe`），就能获得「全能音声工作台」（台本）和「时间轴」两个工作台，
**不需要**装 Python、不需要 pip、不需要模型权重，也不会动你的主界面功能。

- 补丁版本：0.19（2026-10-27）
- 工作台原名「长篇台本」，0.11 起改名「全能音声工作台」
- 对应主程序：IndexTTS2 v3 便携包（Python 3.11 / FastAPI / `/api/v1`）
- 体积：约 190MB 解压后 / 约 135MB 压缩包，其中
  - 87MB 是**内置 ffmpeg**（`bin\ffmpeg.exe`，视频抽音频用，装上就能用、不需要联网）
  - 80MB 是 **Demucs 的 htdemucs 权重**（`vendor2\torch\`，「去伴奏」离线可用）
  - 都不需要的话可以删掉对应目录，功能会退化成「只有普通音频导入 / 只有 DSP 中置提取」

> **0.14 只改打包，不改功能**：`安装.bat` 重写成**纯 ASCII**、安装器改名 `install.py`。
> 0.13 及更早的 bat 里写了中文，在中文 Windows 的 cmd（GBK 代码页）下会变成
> `'t' 不是内部或外部命令` / `'版湰' 不是内部或外部命令` 一串报错，双击根本装不上。

---

## 一、装之前先确认

目标整合包里应该有这些（缺一个就别装，先确认版本）：

```
你的整合包\
  server.py            ← 必须是 FastAPI 主程序（里面有 api = APIRouter(...)）
  web\index.html       ← 主界面
  runtime\python.exe   ← 包内 Python
  checkpoints\         ← 模型（本补丁不需要）
```

## 二、安装（两种方式，任选）

**方式 A：解压进包根目录（推荐）**

1. 把 zip 解压到整合包的**根目录**，会多出一个 `IndexTTS2_全能音声工作台补丁_v0.19` 文件夹；
2. 进这个文件夹，双击 `安装.bat`；
3. 看到 `[DONE] Patch applied.` 后关掉窗口，重新双击包根的 `start_server.bat`。

> `安装.bat` 里**一个中文字都没有**（纯 ASCII + CRLF）。这是故意的：
> cmd.exe 是按系统 OEM 代码页解析 .bat 字节的，UTF-8 写的中文 bat 在 GBK 控制台上
> 会变成 `'t' 不是内部或外部命令` / `'版湰' 不是内部或外部命令` 这种乱码，整个脚本就跑不动。
> 中文提示全部由 `install.py` 打印（Python 走控制台 Unicode 接口，不会乱码）。

**方式 B：解压在别处，指定目标路径**

```bat
runtime\python.exe install.py --target D:\你的整合包
```

**先看看会做什么**（不写盘）：

```bat
runtime\python.exe install.py --target D:\你的整合包 --dry-run
```

安装器只改**两个已有文件**，改之前都会备份到 `_patch_backup\<时间>\`：

| 文件 | 改什么 |
|---|---|
| `server.py` | 在 `if __name__ == "__main__":` 之前插入两段注册块（`register_longform` / `register_timeline`） |
| `web\index.html` | 在页签栏前加一个 `<a href="/longform">长篇台本</a>` 入口 |

其余全是**新增文件**，不碰主程序其它代码。

## 三、装完怎么用

1. 启动服务，首页右上角会多一个 **「全能音声」**；
2. 工作台右上角「保存并进入时间轴」进入时间轴（也可以直接开 `/timeline`）；
3. 第一次打开时间轴会让你建工程，音频会落在这个包的 `longform\` 里；
4. 空间音频 / 混响 / 导出这些都在「时间轴 → 选中片段 → 右侧属性栏」。

## 四、补丁里到底装了什么

```
payload\
  longform_api.py        长篇台本后端（/api/v1/lf/*，页面 /longform）
  lf_import.py           智能导入解析（纯标准库，解析 txt/md/srt/csv/docx…）
  timeline_api.py        时间轴后端（/api/v1/lf/tl/*，页面 /timeline）
  hrir.py                实测 HRIR 双耳渲染（SOFA / npz / 球头回退）
  rooms.py               镜像源房间混响（6 个房间，RT60 标定）
  web\longform.*         台本页（HTML/CSS/JS）
  web\timeline.*         时间轴页（HTML/CSS/JS，含空间音频面板、三视图）
  web\emoctl.js          共用的情感控件（两页同一套）
  assets\hrir\           KEMAR 远场（SOFA）+ KU100 近场两套（npz）
  _vendor\h5py\          读 .sofa 需要（cp311-win_amd64；npz 不需要）
  vendor2\               Demucs 人声分离（可选增强，缺了自动退回 DSP）
  longform\ outputs\ logs\   空目录骨架
```

**不含**：模型权重、你原来的台本/音效、我的测试脚本、`runtime` 本身。

## 五、排错

| 现象 | 原因 / 处理 |
|---|---|
| 安装器说「没有 api = APIRouter」 | 目标包不是同款 v3，或路由结构被改过。把 `register_longform(app, api, deps=…)` 手工挂到它的 router 上（见 docs/技术路线 §6） |
| 首页没有「全能音声」 | `web\index.html` 里没有 `<nav class="tabs"` 这个锚点。手工加一行 `<a class="tab" href="/longform">全能音声</a>` 即可 |
| 打开 /longform 404 | 注册块没插进去（看 server 启动日志有没有 `Longform extension failed`）。多半是 `tts` / `current_dir` 变量名不同，按报错改那几行 |
| 启动日志 `Longform extension failed: No module named 'soundfile'` | 目标包缺依赖。这份补丁假定目标包=runtime 里有 numpy/soundfile/scipy/fastapi（同款 v3 都有） |
| 空间音频里 HRIR 只有「球头近似」 | `assets\hrir` 没拷全，或 `_vendor\h5py` 与目标 runtime 的 Python 版本不匹配（本包按 3.11 打包；npz 那两套不受影响） |
| 音效分离没有 Demucs | 正常：`vendor2\` 缺失或依赖不全时自动退回 DSP 中置提取，主流程不受影响 |
| 想改回原样 | `runtime\python.exe install.py --restore`（还原 backup 里的 server.py / index.html），再手工删掉新增文件 |
| 双击 `安装.bat` 出现 `'xxx' 不是内部或外部命令` | 说明 zip 解压时被别的东西改过/替换过 bat，或者你拿到的是 0.12 及更早的包（那版 bat 里带中文）。0.14 的 bat 是纯 ASCII，不会出这个；实在不行就直接在包根开 cmd 跑 `runtime\python.exe install.py` |
| `[ERROR] Python not found.` | 这个补丁文件夹不在整合包里面（`runtime\python.exe` 找不到），也没装系统 Python。把整个文件夹挪到包根下再双击，或按提示用 `--target` 指定路径 |

## 六、卸载

1. `runtime\python.exe install.py --restore`（还原两个被改的文件）；
2. 删掉 `longform_api.py`、`lf_import.py`、`timeline_api.py`、`hrir.py`、`rooms.py`；
3. 删掉 `web\longform.*`、`web\timeline.*`、`web\emoctl.js`；
4. 想彻底清干净再删 `assets\hrir\`、`_vendor\`、`vendor2\`、`longform\`（注意 `longform\` 里有你写的台本）。
