最短流程 · 约 10 分钟

第一次用？从一段文字到一条混音，只要六步

全能音声工作台做的是「长篇台本 → 分句配音 → 贴音效 → 摆空间 → 出混音」。 下面这条是最短可用路径，每一步只讲必须做的事；走通一遍之后， 最下面的「全功能地图」把其余能力（分组、筛选、素材库、清理空间、关键帧、空间音频、导出方案…）都列了一遍。

1导入台本 2提取音色 3生成音声 4加入音效 5时间轴编辑 6导出混音 ▦全功能地图 ⌘快捷键 ?常见问题

1导入台本 一段文字变成「一句一行」

位置：左边「我的台本」→ ⋯ 更多 → 新建 / 导入
  1. 点左侧 ⋯ 更多 → 新建台本，把文稿整段粘进去；或者直接 导入 .txt。
  2. 分行方式选 按标点断句（推荐）：一句一行，后面生成、试听、重生成都以「句」为单位。
  3. 想改哪一句，直接点文本改；行尾的数字是字数，括号里是时长。
小技巧：顶部工具条上的「智能分行」可以把一大段按长度或标点重新切开；「历史」里存着每次保存的快照，改乱了能退回去。

2提取音色 告诉它「用谁的声音念」

位置：右上 🎙 音色素材库（或 📥 素材导入台）
  1. 把一段干净的参考音频（5～15 秒、一个人、没有背景音乐）拖进 素材导入台。
  2. 在导入台里点 存入音色库，起个名字（比如「旁白-男」）。视频也能直接拖进来，会自动抽成音频。
  3. 回到台本，右侧 全局默认参数 里选这个音色，或者选中若干句 → 批量改属性 只给这几句换音色。
已经内置：ffmpeg（视频抽音频）和 Demucs（去伴奏 / 只留人声）都随包提供，不需要联网下载。导入台底部那一行状态是绿点就说明可用。

3生成音声 先小样，再整篇

位置：右侧 生成 页签
  1. 先选中 1～2 句 点「生成选中」，试听一下音色、情绪、语速对不对。
  2. 满意了再 全选 → 开始生成。第一次会先加载模型（右侧顶部状态条由灰变绿），之后每句大约几秒。
  3. 生成完，句子右边会显示 实际时长；改过文本或参数的句子会标「待重生成」。
  4. 某一句不满意：点行尾 ⟳ 重生成，或者 ⋯ → 改属性并重生成 只改这一句的音色 / 情感。
注意：改「全局默认参数」会影响所有没单独设置过的句子，所以会先弹确认框。手滑了就用工具条的 ↩ 撤回属性。

4加入音效 用标签标「什么时候响」

位置：句子行首 ＋（句中标签）／行尾 ⋯ → 在下面插入句间标签
  1. 句中标签：点行首 ＋ → 选或输入标签名（如「关门」）→ 拖位置滑杆选落在第几个字 → 「音效」里挑一个 → 试听。
  2. 句间标签：行尾 ⋯ → 在下面插入句间标签，适合「段落之间的转场」。留白就是给音效留的时间。
  3. 句中标签默认带 500ms 延迟，避免和上一句末尾的句间标签挤在同一时刻。
  4. 标签不会改变这一句的音频，它只是标记位置；进入时间轴后，音效素材会自动落在对应时刻。

5进入时间轴编辑 排位置、调空间、修节奏

位置：台本顶部 🎬 时间轴 按钮（会新建一份工程副本，原台本不动）
  1. 语音片段按台本顺序自动铺在音声轨上，标签音效落在对应时刻。
  2. 拖片段改位置；拖右边缘改长度。选中多段后拖其中一段，会整组一起移动。
  3. 选中片段 → 右侧属性面板改音量 / 声像 / 淡入淡出 / 速度；位置、时长、源内起点 都是「数字框 + 滚动条」。
  4. 页面顶部的 ↕ 重排音声延迟：按台本里的句间停顿，把所有音声片段按句子顺序重新排一遍（只改开始时间）。
  5. 想让一段语音反复用：右键 → ⧉ 复制到素材轨「音声副本音轨」，副本跟台本彻底脱钩，怎么剪都不影响原句。
空间音频：选中片段 → 右侧「空间」页签 → 选一个预设（如「贴耳微晃」「掠耳而过」）就能一键铺关键帧；也可以在图形面板上手动拖点。

6导出混音 一条成品音轨

位置：时间轴右上 导出混音
  1. 选格式（WAV / MP3 / FLAC）、采样率、声道；需要的话勾「只导出某几条轨」。
  2. 总时长算到哪儿：按最后一段的「显示末端」（眼睛看到的长度）或「未显示部分末端」（被裁掉的那截也算）。
  3. 点导出，成品会出现在 outputs/，页面上也能直接下载 / 试听。
只想快速拼一条小样？台本右侧「导出」页签里有「拼接导出」，直接按句序拼 WAV，不进时间轴也能出片。

全功能地图

下面按「一篇文章 → 一条成品」的顺序排：备料 → 台本 → 生成 → 时间轴 → 导出。 每个阶段先说这一步要解决什么，再列出这个阶段会用到的功能；想跳到某一步，点上面的流程导航即可。

阶段 1

备料

把文字和声音素材先弄进系统

智能导入 台词怎么切

位置：顶栏 新建（粘文本建新台本）／左边栏 ⋯ 更多 → 导入（追加到当前台本）
① 选文件 / 粘贴文本→ ② 识别类别（可手改）→ ③ 预览编辑（可拆/并/改分组）→ 导入（每个分组 = 一个批量任务）

导入器会先判断这份稿子属于哪一类（会在第 2 步列出判断依据和置信度，也可以点别的类别重判）， 再按这一类的规则切行。所有规则都只是建议——第 3 步预览里每一段都能改。

A. 三种分行方案（纯文本类最常用，其它类等价）
方案怎么切适合注意
按长度
切句后合并（默认）		 先按句末标点 。！？!?… 和换行切成小句，再往后合并，直到接近「单段上限」（默认 70 字）。 口播稿、讲稿、小说正文——最通用 引号 / 括号内部不切；单句本身超上限时，才在逗号顿号处软切
一句一行 一个句末标点一行，不再合并。短句也各占一行。 逐句精修、要给每句单独挂标签 / 单独重做 行数变多，生成次数也变多；上下文会碎
一段一行
按空行		 按空行分段，每段 = 一行（段内仍受单段上限约束）。 已经排好版的口播稿、每段就是一口气念完的 段落太长会被再切；没有空行的稿子会变成一整行
B. 五类稿子的识别规则
类别靠什么认出来怎么切 / 怎么处理
⏱ 时间轴类 行首带时间码 00:00:01 / [00:01.500]，或 SRT / VTT 字幕 按时间码切、保留原时间轴；可把稿子里的停顿标记转成静默（并设停顿上限）。进时间轴后位置就是稿子里的时间。
🎭 剧本类 角色：台词 前缀、引号、括号动作提示 按角色切。角色名只进「分组 / 备注」不进正文；同一角色连说的几句可以合并到上限；括号里的动作可写进备注（不朗读）。
📖 小说类 章节标题（第 x 章 / # 标题） 按章节切段、默认按章节分组；可让括号里的内容「不念」。
🏷 指令类 【镜头】、[pause=500] 这类标记 标记本身不朗读：可以变成停顿、变成分组名，或只写进备注。
🧩 纯文本 以上特征都没有 用上面 A 的三种方案。默认「按长度」。
C. 切完之后：上限、分组、停顿、预设
  • 单段上限（默认 70 字 / 纯文本，剧本 70、小说 80、指令 60）：一行最长多少字。超过会被切开。
  • 分组：不分组 / 按章节 / 按角色 / 按场景 / 每 N 段一组。分组决定后面「批量生成」的单位，长文建议每 30 段一组。
  • 每段后加停顿：批量给每段末尾加静音（台本里存成停顿值）。
  • 预设：每类都有几个一键配置，比如「口播稿（按长度）」「逐句精修（一句一行）」「按段落」「长文分批（每 30 段一组）」——选完还能再改单项。
  • 预览里能改什么：拆分一行、合并两行、改分组、改文字；超过上限 / 空行这类问题会标出来。确认后一次导入。

素材导入台 声音素材进门

位置：顶栏 📥 素材导入台（或从音色库 / 音效库点「导入」）
  • 拖入音频或视频 → 先落到「导入台」这个中转站，还不是正式素材。视频会自动抽音频（ffmpeg 已内置）。
  • 常用处理：去伴奏 / 只留人声（Demucs，离线权重已内置）、中置提取（DSP，轻量、不占显存）、 降噪、标准化、裁掉首尾静音、重采样、裁剪。
  • 处理完默认保留原素材（方便换参数再试），确认好了再「存入音色库 / 音效库」。
  • 底部一行是 ffmpeg 状态：绿点 = 可用。换机器没带上时，可以上传或指定路径。

三个素材库怎么分工 别搞混

位置：顶栏 🎙 音色素材库 / 🔔 音效素材库 / 📥 素材导入台
  • 音色库（全局）：参考音频，决定「用谁的声音念」。5~15 秒、一个人、干净，效果最好。
  • 音效库（全局）：短音频（关门、脚步、风、转场）。台本标签可以挂，时间轴也能直接插。
  • 导入台（中转）：还没决定归哪儿的东西，处理完再分拣；不进正式库，随时可以清。
  • 同一个音频在多处各存一份是正常的（工程里还会存副本），「清理空间」会告诉你谁占地方。
阶段 2

台本

分行、分组、把要改的句子挑出来

我的台本 源文件 / 工程

位置：左边栏，分两组显示
  • 台本（源文件）：你导入的那份文字。生成、改属性都在这里。想追加内容用「⋯ 更多 → 导入」。
  • 工程（时间轴副本）：第一次点「时间轴」时自动生成。之后所有剪辑改动只进副本，源文件不动；想退回起点用工程页的「回到初始样本」。
  • 多选：Ctrl 点加选 / Shift 点连选；选中后出现批量条，可一次删除 / 复制多份；Esc 取消。

智能分行 导入后重切

位置：工具条 智能分行
  • 两种模式：按标点分句（一句一行）／按长度合并（短句并到接近上限）。
  • 可设每行字数上限；可选处理范围：只处理「未生成 / 需重生成」的行，或全篇（全篇会把已生成的标成待重生成）。
  • 导入时分错了，用它重切就行，不用重新导入。

分组 批量任务的单位

位置：右侧 批量 页签
  • 一组 = 一批句子 + 一套音色/情感参数。旁白、对话、内心独白分开，生成和重做都能按组来。
  • 「新建分组」收进当前选中的句子；卡片上的「生成 / 编辑」只作用于这一组；「选中未分组」找漏网的。
  • 时间轴里也能按组多选（右键语音片段 → 选中同组）。

筛选与状态 找问题句

位置：工具条下面那排「筛选」+ 顶部统计
  • 按状态（未生成 / 已生成 / 待重生成 / 失败 / 有标签 / 已改动）、音色、分组过滤。
  • 顶部「改动 N」只看和生成时不一样的句子——改完稿回来重生成时最常用。
  • 「选中」支持区间写法 1-20,25,30-，圈一批很快。
阶段 3

生成

把文字变成声音，顺手把音效位置标好

批量生成与单句重做 主流程

位置：右侧 生成 页签 / 行尾 ⟳
  • 范围三选一：选中行 / 未生成 / 全部，再点「开始生成」；可随时「停止」，已完成的不会丢。
  • 先试 1~2 句确认音色和情绪，再整篇跑，省时间。
  • 单句重做：行尾 ⟳；只改这一句的参数：⋯ → 改属性并重生成（不影响别的句子）。
  • 生成完行上显示实际时长（不是估算），时间轴按实际时长排；文本或参数改过会标「待重生成」。
  • 顶部状态条常驻：模型是否加载、ffmpeg、人声分离，切页签也看得见。

句中标签 / 句间标签 给音效留位置

位置：行首 ＋（句中）／行尾 ⋯（句间）
  • 句中：落在「第 N 个字之后」，用来对齐台词里的动作（说到「关门」时咔嚓一声）。默认带 500ms 延迟，避免和上一句末尾挤在同一时刻；位置用数字框 + 拖动条调，旁边会算「句中约 x.xx 秒」。
  • 句间：插在两句之间，留白会真的插入静音，给转场音效留时间。
  • 两者都能挂音效（可试听、调音量）；进时间轴后自动变成对应时刻的素材片段。
  • 标签本身不出声、不改音频，只标位置；删标签 = 删对应的音效片段。
阶段 4

时间轴

排位置、调属性、做空间与自动化

时间轴常用操作 剪辑

位置：台本页 🎬 时间轴（会新建工程副本）
  • 拖片段改位置、拖边缘改长度；选中多段拖一段会整组移动；框选、Ctrl 点加选、Shift 连选。
  • 顶部标尺常驻（滚到下面也贴着），拖标尺 = 定位播放头；空格播放/暂停，M 打标记，↑↓ 跳切点。
  • ↕ 重排音声延迟：按台本句序 + 句间停顿，把跨轨的音声片段重新排成一条时间线（只改开始时间）。
  • ⇄ 整理重叠：同轨叠在一起时一键挪到空白轨；总时长会跟着片段末端自动变长，也可点顶栏总时长手改。

片段属性 右侧面板

位置：选中片段 → 右侧「片段属性」
  • 位置 / 时长 / 源内起点都是「数字框 + 滚动条」。
  • 音量、声像、淡入淡出、速度（滑杆居中 = 1×）与变速时长（填目标秒数自动算速率）。
  • 右键：复制 / 剪切 / 粘贴、复制属性 / 选择性粘贴、切开、恢复完整片段、删除。
  • 语音片段还能「⧉ 复制到音声副本音轨」——副本是独立素材，随便剪都不影响台本。

轨道属性 整轨操作

位置：左侧轨道头（双击改名 / 右键 / ⋯）
  • M 静音、S 独奏；拖轨道头上的音量条改整轨音量。
  • 右键 → 整轨混响、把复制的属性套到整轨、整轨统一音量，几十段一次改完。
  • 排序：移到音声/素材轨组第一条 / 最后一条、组内上移下移；两组永远不会互相穿插。

高级：关键帧 / 录制 / 空间音频 / 运动脚本 进阶

位置：片段属性下半部分（Alt+K 显示/隐藏关键帧面板）
  • 关键帧：音量、声像、空间距离都能画曲线。「＋ 播放头加点」或 Alt+点片段直接加；点可拖动、右键删；曲线形态可选平滑/折线。
  • 关键帧录制：点「● 录音量」再播放，一边听一边推滑杆，自动把动作记成关键帧；再点一次停止。
  • 空间音频：开启后选房间（混响）+ 干湿比 + HRIR 数据集，再用方位/仰角/距离摆位；圆形面板可直接拖人头周围的位置。
  • 运动脚本：左右往返 / 绕头圆周 / 由远及近 / 前后穿越 / 8 字 / 螺旋 / 贴耳微晃 / 头顶环绕 / 掠耳而过 / 远近呼吸 / 背后低语…选一个自动铺一串关键帧，再微调。
阶段 5

导出与维护

出成品、给后期、收拾硬盘

导出方案 出片

位置：时间轴 导出混音 / 导出工程；台本 导出 页签
  • 导出混音：一条成品（WAV / MP3 / FLAC / OGG），可选采样率、声道、只导某几条轨、只导某个时间段； 「总时长算到哪儿」决定尾巴按显示末端还是未显示末端（被裁掉/变速压掉的那段也算），有混响尾巴会多留一点。
  • 导出工程：Reaper（.rpp，最全：位置/裁剪/音量/声像/淡入淡出/自动化）、PR / 达芬奇（.edl）、 Audacity（分轨 WAV + labels.txt）。包里一定带分轨 stems、timeline.csv、markers.csv、说明。
  • 勾「把用到的音频一起打包」= 自包含，发给别人也能直接打开；不勾则引用本机路径，体积小。
  • 有片段的音频文件不见了时会跳过并提示「有 N 段被跳过」；一个能出声的片段都没有时直接报错，不会给你一个空包。
  • 单句导出：片段右键 → 导出这段；拼接导出：台本「导出」页签里按句序直接拼一条，不进时间轴。

清理空间 维护

位置：顶栏 🧹 清理空间
  • 分类列出：回收站、导出产物、历史快照、波形缓存、重复素材，按体积排序。
  • 可以只删某一类（比如 90 天前的历史快照），不动你正在用的台本和音频。
  • 删掉的东西进回收站，能在 longform/_trash 里找回。

快捷键小抄

台本作用
Ctrl + Z / Ctrl + Shift + Z撤销 / 重做（文本和属性都算）
Ctrl + Alt + C / V复制 / 粘贴选中的句子（连已生成的音频一起）
Shift + 点行连续选一段
时间轴作用
空格播放 / 暂停
Ctrl + C / X / V复制 / 剪切 / 粘贴片段（多选时整组）
Ctrl + Shift + C / V复制片段属性 / 选择性粘贴（含关键帧）
Ctrl + 点片段加选 / 减选（多选）
Del删除选中片段（语音片段不能删，要回台本删句子）
M / Shift + M打标记 / 跳到下一个标记
Alt + 点片段在点击处加一个关键帧

卡住了？先看这几条

拖视频进导入台，没反应 / 提示没有 ffmpeg

补丁包已经内置 ffmpeg（bin\ffmpeg.exe）。如果状态条还是黄点，点它右边的 ⟳ 重新探测； 还不行就 ✎ 填路径 指到任意一个 ffmpeg.exe，或者 ⬆ 上传 一个（一次就够，会记进配置）。

「去伴奏 / 只留人声」显示不可用

Demucs 的模型权重（80MB）已经随包内置在 vendor2\torch，正常是离线可用的。 如果状态显示不可用，多半是这个目录被删了——重新装一次补丁即可（补丁里带着它）。

点生成没声音 / 卡在「加载模型」

第一次生成要先加载 TTS 模型，机器慢的话要几十秒，这是正常的；右侧顶部状态条会从灰点变成绿点。 一直不动就看 logs\server.log 最后几行。

时间轴里片段拖到最右边，总时长不涨？

已修：松手后总时长会自动撑到片段末端。也可以直接点顶栏的「总时长」手动改。

单句想反复用，又不想影响台本

在时间轴里右键那一句 → ⧉ 复制到素材轨「音声副本音轨」。副本是一条独立音频，可以随便剪、变速、删，都不会动到台本里的原句。

想从头再来一遍

台本页「⋯ 更多 → 历史」里存着每次保存的副本，挑一个还原即可。文件层面在 longform\scripts\，回收站在 longform\_trash\。
